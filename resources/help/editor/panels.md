# パネル

どのソフトにもある、核のパネルです。ウィンドウ メニューで開く / 閉じるを切り替えます。

| パネル | すること |
|---|---|
| ヒエラルキー | ソフトの中身を木で出します (ゲームならシーンのエンティティ)。クリック・Ctrl・Shift で選ぶ、ドラッグで並べ替え・親子付け、F2 かダブルクリックで名前の変更、上の欄で検索、右クリックでメニュー |
| インスペクター | 選んだものの値を出し、変えられます。変えたことはすべて元に戻せます (Ctrl+Z) |
| コンソール | ログ (お知らせ・注意・エラー) が流れます |
| アセット | プロジェクトの `Assets` フォルダーのファイル。ドラッグでインスペクターの欄やシーンへ |
| ヘルプ | このヘルプ。最初は閉じています (F1 で開く) |

ソフトが自分のパネル (シーン・ゲーム など) を足します。その説明は「プラグイン」のタブにあります。
