# エディター

Hub からプロジェクトを開くと出る画面です。

## 上の帯
- **メニュー**: ファイル (保存・Hub に戻る・終了)・編集 (元に戻す・やり直し)・ウィンドウ (パネルを開く / 閉じる・配置)・プラグイン (入れる)・ヘルプ・デバッグ
- **ソフトのタブ**: プラグインが出す「ソフト」(ゲーム など) を切り替えます。ソフトごとに、パネルの配置と元に戻す (Undo) の履歴を持ちます

## 保存
- **Ctrl+S** で保存します。保存していない変更があると、タイトルに `*` が付きます
- 閉じるときに保存していない変更があれば、保存するかを聞きます
- 自動保存の間隔は Hub の「オプション」で決めます

続きは [パネル](panels)・[ドッキング](docking)・[ショートカット](shortcuts) を見てください。
