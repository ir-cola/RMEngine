# RM Engine Help

How to use RM Engine. Pick a page from the list on the left.

- **Hub and editor** tab: the Hub (the screen where you pick a project) and the editor frame (menus, panels, docking)
- **Plugins** tab: help for each installed plugin. It grows when you install a plugin and goes away when you remove it. Help for connector plugins (such as "Weather × Physics") is under the plugin they connect to

> In the editor, press **F1** or use Help → Help in the menu to open this panel. Like any other panel, you can drag its tab anywhere.

The box above the list searches page names.
