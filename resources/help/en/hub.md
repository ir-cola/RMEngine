# Hub

The first screen you see when RM Engine starts. Switch pages with the sidebar on the left.

## Projects
- Recently opened projects. Click a column header to sort, and use the box above to search
- **New**: pick a template (empty, 3D game, 2D game ...), a name and a folder
- **Open**: pick a `.rmpf` file
- Right-click a row (or "…"): open, rename (with its folder), show in Explorer, remove from the list

## Plugins
- The installed plugins. Install, reinstall or remove them
- Required plugins come along. Removing a plugin that others need warns you first
- **Plugins you can download**: new plugins and new versions from the list on the web

## Updates
What changed in each version.

## Options
Color theme, language (Japanese / English), auto-save interval, checking the engine files (repairs broken plugins) and more.
