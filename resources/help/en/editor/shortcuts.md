# Shortcuts

| Key | What it does |
|---|---|
| Ctrl+S | Save (even while typing) |
| Ctrl+Z | Undo |
| Ctrl+Y / Ctrl+Shift+Z | Redo |
| F1 | Open the help |
| F2 | Rename in the Hierarchy |
| Ctrl+A | Select all in the Hierarchy |

Keys for software panels such as the scene view are on each page of the Plugins tab.
