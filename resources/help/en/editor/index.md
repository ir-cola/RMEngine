# Editor

The screen you get when you open a project from the Hub.

## The top bar
- **Menu**: File (save, back to Hub, quit), Edit (undo, redo), Window (open / close panels, layouts), Plugins (install), Help, Debug
- **Software tabs**: switch between the "software" plugins provide (such as Game). Each software has its own panel layout and undo history

## Saving
- **Ctrl+S** saves. Unsaved changes put a `*` in the title
- If you close with unsaved changes, you are asked whether to save
- Set the auto-save interval in the Hub's Options

See also [Panels](panels), [Docking](docking) and [Shortcuts](shortcuts).
