# Docking

Put panels wherever you like. The arrangement is remembered per project and per software.

- **Drag a tab**: reorder, move to another panel's tabs, or split up / down / left / right (drop on the guide that appears)
- **Drop outside the guides**: the panel becomes its own window. Drag its tab or title bar back into the editor
- **Drag a divider**: resize
- **Close**: the tab's ×, a middle click, or the right-click menu
- **Window menu**: reopen panels, save the current layout under a name, reset to the first layout

> The layout is how you see things, not project data. It is not part of undo and does not mark the project unsaved.
