# Panels

The core panels every software has. Toggle them in the Window menu.

| Panel | What it does |
|---|---|
| Hierarchy | Shows the software's contents as a tree (for a game: the scene's entities). Click, Ctrl and Shift to select, drag to reorder and parent, F2 or double-click to rename, search with the box at the top, right-click for a menu |
| Inspector | Shows the values of what you selected and lets you change them. Every change can be undone (Ctrl+Z) |
| Console | The log (info, warnings, errors) |
| Assets | The files in the project's `Assets` folder. Drag them onto inspector fields or the scene |
| Help | This help. Closed at first (F1 opens it) |

Software adds its own panels (Scene, Game ...). Their help is on the Plugins tab.
