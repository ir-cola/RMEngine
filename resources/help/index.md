# RM Engine のヘルプ

RM Engine の使い方の説明です。左の一覧からページを選びます。

- **Hub とエディター本体** のタブ: Hub (プロジェクトを選ぶ画面) と、エディターの枠 (メニュー・パネル・ドッキング) の説明
- **プラグイン** のタブ: 入っているプラグインごとの説明。プラグインを入れると増え、消すと消えます。つなぎのプラグイン (「天候 × 物理」など) の説明は、元のプラグインの下にあります

> エディターでは **F1** か、メニューの「ヘルプ」→「ヘルプ」で、このパネルを開けます。パネルはほかのパネルと同じように、タブをドラッグして好きな所に置けます。

一覧の上の欄で、ページの名前を検索できます。
