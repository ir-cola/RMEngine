# 試し方 (いま作ってあるもの)

ここまでに作ったものを、試す順に全部書く。機能を足したらここも直す。
画面の確認はユーザーが自分で行う (Claude はコンピューター操作で確かめない)。確かめていないことは 7 章に「未確認」として書く。

---

## 0. 準備

**ビルド**

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\build.ps1
```

- 本体は `build\bin\x64\Debug\RM_Engine.exe` にできる
- Visual Studio で `RM_Engine.sln` を開いても動かせる (スタートアップは RM_Engine)
- `RM_Engine.exe --project <ファイル>.rmpf` で、そのプロジェクトを開く (確認のために Hub は一度出る: 5 章)
- 「デバッグ」メニューは Debug ビルドにだけ出る

**ファイルの置き場所**

| 場所 | 中身 |
|---|---|
| `%APPDATA%\RM_Engine\hub.json` | 最近のプロジェクト・最後に使った保存先・「この状態が変わるまで表示しない」の記録 |
| `%LOCALAPPDATA%\RM_Engine\Logs\editor.log` | ログ (起動ごとに上書き)。エディターのコンソールと同じ中身 |
| `%LOCALAPPDATA%\RM_Engine\Plugins\<作者>\<名前>\` | インストールしたプラグイン |
| `build\bin\x64\Debug\Plugins\` | エンジンが持っているプラグイン (ビルドで写される) |
| `<プロジェクト>\<名前>.rmpf` | プロジェクトファイル (JSON) |
| `<プロジェクト>\Assets\` | 素材 |
| `<プロジェクト>\UserSettings\Layout.json` | パネルの配置 (個人の設定) |

## 1. Hub

**ウィンドウ**

- 起動すると「RM Engine Hub」が出る (1280×760、最小 980×600)
- 左のサイドバーにロゴ、「プロジェクト」「プラグイン」、版 (0.0.1)

**プロジェクトのページ**

- **新規作成** (Ctrl+N) でダイアログが開く
  - テンプレートは「白紙」だけ。名前の欄には最初からカーソルが入っている
  - 保存先は欄に直接書くか「参照…」で選ぶ。下に、作られるパスが出る
  - 既定の保存先は「ドキュメント\RM_Engine Projects」(初回)。2 回目からは最後に使った場所
  - Enter で作成、Esc で閉じる
  - 作ると `<保存先>\<名前>\<名前>.rmpf` と `Assets\` ができ、エディターが開く
- **名前のエラー表示** (試してみる):
  - 空
  - 65 文字以上
  - `\ / : * ? " < > |` を含む
  - `CON` `NUL` `COM1` などの予約名
  - 先頭が空白
  - 末尾が `.` か空白
- **開く…** (Ctrl+O): `.rmpf` を選ぶダイアログ
- **一覧**
  - 検索欄で名前・場所を絞り込む
  - 見出し (名前 / 更新日時 / 場所) を押すと並べ替え、もう一度押すと逆順
  - ダブルクリックか、選んで Enter で開く。F5 で読み直す
- **行の「…」ボタンか右クリック**のメニュー
  - 開く
  - エクスプローラーで表示
  - 一覧から外す (ファイルは消さない)
- **ファイルが消えたプロジェクト**は「見つかりません」と出る。開こうとするとエラーになり、そこからも一覧から外せる

**プラグインのページ** → 5 章

## 2. エディター

**ウィンドウ**

- 開くと最大化される。タイトルは「<名前> - RM Engine」で、未保存のときは先頭に「* 」が付く
- 下のステータスバーに、プロジェクトのパスと「保存済み」/「● 未保存の変更があります」

**メニュー**

| メニュー | 項目 |
|---|---|
| ファイル | 保存 (Ctrl+S) / Hub に戻る / 終了 |
| 編集 | 元に戻す (Ctrl+Z) / やり直し (Ctrl+Y か Ctrl+Shift+Z) |
| ウィンドウ | パネルごとの表示 (✓ 付き) / パネルの配置を元に戻す |
| プラグイン | プラグインの一覧と、インストール (5 章) |
| ヘルプ | RM Engine について |
| デバッグ | 未保存の変更を作る (テスト用。Debug ビルドだけ) |

- メニューを 1 つ開いた状態で隣の見出しにマウスを乗せると、そちらに切り替わる。Esc で閉じる

**閉じ方**

- 「×」は Hub に戻り、「ファイル > 終了」はアプリを終わらせる
- 未保存の変更があると、どちらも確認が出る
  - キャンセル (Esc)
  - 保存せずに閉じる
  - 保存して閉じる (Enter)
- 試し方: 「デバッグ > 未保存の変更を作る」で「*」が付くので、そこから閉じてみる

## 3. パネルのドッキング

**タブ**

- クリックすると、そのパネルが表に出る
- 「×」はアクティブなタブか、マウスを乗せたタブに出る。中クリックでも閉じる
- 右クリックのメニュー
  - 閉じる
  - 別ウィンドウに出す
  - エディターのウィンドウに戻す (別ウィンドウの中のタブだけ)

**タブをドラッグする** (6 DIP 動かすと始まる。タブ名の札がマウスについてくる)

- **下にあるパネルの真ん中**に、十字の目印が 5 つ出る (中央と上下左右)。パネルが小さいと中央だけ
- **ウィンドウの四辺の中ほど**にも目印が出る (パネルが 2 つ以上あるとき)
- 目印に乗ると、行き先が赤く塗られる。離した先によって次のようになる

| 離した場所 | どうなるか |
|---|---|
| 端の目印 | そこで分割される |
| 中央の目印、または別のパネルのタブ列 | タブとして入る (タブ列なら離した位置に。同じ列の中で並べ替えもできる) |
| どの目印でもない所 (メニューバーの上なども) | そのパネルが**別ウィンドウ**になる |

- Esc でドラッグをやめる

**仕切り**

- パネルの間をドラッグすると大きさが変わる。カーソルが ↔ / ↕ になる
- 片側が 80 DIP より小さくはならない
- 大きさは比率で覚えるので、ウィンドウを大きくすると全部が伸びる

**別ウィンドウ**

- エディターの上に乗り続けるウィンドウで、タスクバーには出ない。タイトルは中のパネル名
- 中でも、タブ・仕切り・目印・分割が同じように使える。ほかのパネルを入れることもできる
- 別ウィンドウのタブをエディターへ (逆も) ドラッグできる
- **タイトルバーを持ってエディターの上へ動かす**と目印が出る。目印の上で離すと、中のパネルごと戻る
- 別ウィンドウの「×」を押すと、中のパネルは閉じる (「ウィンドウ」メニューから開き直せる)
- 別ウィンドウにフォーカスがあっても、Ctrl+S / Ctrl+Z は効く

**保存**

- 配置は、保存したときとエディターを閉じたときに `UserSettings\Layout.json` へ書かれる
- 次に開くと、別ウィンドウの位置も含めて元に戻る
- 保存した位置がもう無いモニターの上なら、画面の中に移して出す
- 配置を変えても、未保存 (「*」) にはならない

**「ウィンドウ」メニュー**

- 閉じたパネルを選ぶと、一番大きいパネルにタブとして戻る
- 「パネルの配置を元に戻す」で、最初の配置に戻る

## 4. ソフト

**ゲーム制作プラグインが使えるとき**

- 上のタブに「ゲーム」が出る
- 最初の配置は、左に階層、中央にシーン / ゲーム、右にインスペクター、下にコンソール / アセット
- シーンとゲームのパネルは、まだ説明の文字だけ
- 「ゲーム」パネルに**「ゲームの設定を開く」**ボタンがある (6 章)

**ゲーム制作プラグインが使えないとき**

- タブ列には「ソフトはまだありません…」と出る
- パネルは階層・スタート・インスペクター・コンソール・アセット

**ソフトごとに分かれているもの**

- パネルの配置と Undo の履歴は、ソフトごとに別々。未保存の印はプロジェクトで 1 つ
- ソフトが 1 つしかないので、切り替えはまだ試せない

## 5. プラグインの管理

**最初の起動**

- `%LOCALAPPDATA%\RM_Engine\Plugins` が無いと、エンジンが持っているプラグインを全部入れる
- ログに「最初の起動なので…」と出る
- フォルダを消してから起動すると、もう一度この動きを試せる

**Hub の「プラグイン」ページ** (行は「ゲーム制作」1 つ)

| 状態 | 表示 | ボタン |
|---|---|---|
| 入っている | 使用中 | 再インストール / 削除 |
| 入っていない | インストールされていません | インストール |
| 壊れている | ⚠ 使えません: 理由 | 再インストール / 削除 |
| 前提が欠けている | ⚠ 前提が無い: 理由 | 前提をインストール / 再インストール / 削除 |

- **削除**を押すと確認が出る。**Enter も Esc も「いいえ」**。赤い「削除」を押したときだけ消える
- 前提として使われていれば、使えなくなるプラグインの一覧 (間接のものは「○○ を通して」) が出る。最近のプロジェクトのうち使っている数も出る
- 変えた結果は、Hub にその場で反映される

**エディターの「プラグイン」メニュー**

- 入っているものは「名前 (rm_engine / game_production)  使用中」と出る (押せない)
- 入っていないものは「「ゲーム制作」をインストール…」と出る
  - 押すと「保存してから、このプロジェクトを開き直します。元に戻す (Undo) の履歴は消えます」と出る
  - 「保存して開き直す」で、同じプロジェクトが「ゲーム」付きで開き直る
- 削除はできない (Hub だけ)

**プロジェクトを開く前の確認**

1. **起動できません**: そのプロジェクトが使っているプラグインが使えないときに出る
   - 試し方:
     1. 6 章で設定を変えて保存し、`.rmpf` の `plugins` にゲーム制作を記録させる
     2. Hub で削除する
     3. そのプロジェクトを開く
   - 「インストールして開く」で、入れてから開く
2. **お知らせ**: 入っているのに使えないプラグインがあるとき、開く前に 1 回だけ出る (そのプロジェクトが使っていない場合)
   - 試し方: 入れた方の `plugin.json` を `{ broken` などに書き換えて開く
   - ボタンは「インストール」(直してから開く) と「このまま開く」
   - 「この状態が変わるまで表示しない」にチェックすると、同じ状態の間は出ない。使えないプラグインの顔ぶれが変わったら、また出る

- `--project` 付きで起動したときも、まず Hub が出て、そこで確認する
- **ID の食い違い**: `build\bin\x64\Debug\Plugins\...\plugin.json` か、入れた方の `"author"` を変えると「使えません」になる。プラグインは有効にならず、エディターは核のパネルだけで開く

## 6. リフレクションとインスペクター

**開き方**

- 「ゲーム」パネルの「ゲームの設定を開く」を押す
- プロジェクトを開いたときにも、最初からインスペクターに出ている

**項目** (すべて `plugins\rm_engine\game_production\runtime\GameSettings.h` の書き込みから自動で作られる)

| 欄 | 種類 | 決まり |
|---|---|---|
| ゲームの名前 | 文字 | 名前にマウスを乗せると説明が出る |
| 目標 FPS | 整数 | 1〜240 |
| 物理の刻み (秒) | 数 | 0.001〜0.1 |
| 重力 | 3 つの数 | 狭いときは次の行に出る |
| 背景の色 | 色見本 + 4 つの数 | 0〜1 |
| 画面 > 幅 | 整数 | 320〜7680 |
| 画面 > 高さ | 整数 | 240〜4320 |
| 画面 > 表示のしかた | 一覧 | ウィンドウ / フルスクリーン / 枠なしの全画面 |
| 画面 > 垂直同期 | チェック | 説明あり |
| タグ | 配列 | 「0 個 (追加・削除・並べ替えはこれから)」と出て、読むだけ |

**数・文字の欄の動き**

- 確定するのは **Enter** を押したときか、**ほかの所をクリック**したとき。Esc で元に戻る
- 範囲の外の数は収まる (999 → 240)
- 整数は丸める (2.6 → 3)
- 数でない文字や `nan` / `inf` では変わらない
- 1 回確定するごとに Undo 1 回分で、「*」が付く。Ctrl+Z / Ctrl+Y で戻せる

**保存**

- 保存すると、`.rmpf` に `softwareData` と、`plugins` へのゲーム制作の記録が書かれる
- 既定値のままなら何も書かない。開いただけではプラグインに縛られない
- 試し方: 開き直して、値が戻ることを見る

**知らないデータを残す動き**

- `.rmpf` の `softwareData[0].data.settings` に、知らないキー (例: `"abc": 1`) を足す
- `display.mode` を `"Ultra"` にする
- 開くと「表示のしかた」が「Ultra (不明)」と出て、コンソールに警告が出る
- ほかの欄を変えて保存しても、`abc` と `"Ultra"` は残る。一覧で選び直したときだけ上書きされる (Ctrl+Z で `Ultra` に戻る)

**開発側の動き**

- `GameSettings.h` に、`RM_PROPERTY` を付けずにフィールドを書いてビルドしてみる
- `GameSettings.h(行,列): error RM0001: フィールド … に注釈がありません` と出て止まる
- そのほかのエラー:
  - `RM0002`: 属性名の打ち間違い (`Mim=0` など)
  - `RM0003`: 属性の値の形 (`Label=名前`、`Min=定数名`、`Min` が `Max` より大きい など)
  - `RM0004`: 使えない型 (`double`、ポインターなど)
  - `RM0006`: 印の付いていない型
  - ほかに `RM0005` `RM0007`〜`RM0011`
- 正しく足せば、インスペクターと保存に自動で出る
