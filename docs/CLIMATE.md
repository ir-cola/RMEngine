# 気候 (プラグイン「気候」と、つなぎ「天候 × 気候」)

同じシーンの中に、雨の降る所と雪の降る所を作る。マインクラフトのように「雪のエリアに入った瞬間に
雪」ではなく、ゼルダの伝説 ブレス オブ ザ ワイルドのように**土地の気候で降る物が決まり、境目では
少しずつ変わる**ようにする。

## 決まったこと (2026-11-22)

| 項目 | 決めたこと | 決めた人 |
|---|---|---|
| どこに作るか | 天候とは**別のプラグイン「気候」**。天候とは**つなぎ「天候 × 気候」**でつなぐ (今の「天候 × 物理」と同じ形) | ユーザー |
| 2D | 気候エリアは **2D のシーンでも**使える | ユーザー |
| 湿り気 | **気候の側**に持つ (天気以外にも使える: 砂漠の乾き・植物など) | ユーザー |
| 雨か雪か | エリアに「雨」「雪」を直接書かず、**気温で自動に決める** (+2 ℃ 以上は雨、-1 ℃ 以下は雪、間はみぞれ) | ユーザー (2026-11-22) |
| 空の天気 | **両方使えるようにする**。ふだんはシーンで 1 つ (雲・降水量・風・雷)。エリアに「自分の天気」を持たせると、その中ではそちらが勝つ (境目の幅でなめらかに混ぜる)。持たせないエリアはシーンの天気のまま、雨か雪かと降る量だけを気候で変える。エリアの天気は段階 3 | ユーザー (2026-11-22) |

## プラグインの形

| プラグイン | 前提 | 持つもの |
|---|---|---|
| **気候** `rm_engine/climate` | ゲーム制作・3D 空間・2D 空間 (物理と同じ: 1 つのプラグインで 2D と 3D の部品を持つ) | シーンの設定「気候」・部品「気候エリア」(3D) と「気候エリア 2D」・場所ごとの気温と湿り気の計算・スクリプト (`RMClimate.h`)・シーンビューのエリアの枠 |
| **天候** (今のもの) | 変わらない | 天候だけのときは今と同じ (「雪にする」でシーン全体が雨か雪) |
| **天候 × 気候** `rm_engine/weather_x_climate` (つなぎ・段階 1-b) | 天候・気候 | 天候の新しい口 (「この場所でどれだけ雪になるか・降る量の倍率」) に、気候の気温と湿り気から答える |

天候は気候を知らない (一般の口だけを持つ)。気候も天候を知らない。

## 気候の中身

### シーンの設定「気候」 (エリアの外の気候)

- **気温 (℃)**: 既定 15
- **湿り気 (%)**: 既定 50
- **高さで冷える (℃ / 100 m)**: 3D だけ。高い所ほど気温が下がる。既定 0.6 (本物の空気くらい)。山の上だけ雪、が自然にできる
- **基準の高さ (m)**: この高さで上の気温になる

設定が無いシーンも、既定の値の気候として答える。

### 部品「気候エリア」(3D) / 「気候エリア 2D」

| 項目 | 意味 |
|---|---|
| 形 | 3D: 箱 / 円柱 (縦が高さ)。2D: 長方形 / 円 |
| 大きさ (3D) / 広さ (2D) | Transform の大きさを掛ける。回転も付いてくる |
| 境目の幅 (m) | 縁からこの幅だけ内側へ、外の気候から中の気候へなめらかに変わる (0: 縁で切り替わる) |
| 気温を変える・気温 (℃) | 切ると気温はそのまま (湿り気だけ変えるエリア: 霧の谷など) |
| 湿り気を変える・湿り気 (%) | 切ると湿り気はそのまま |
| 優先度 | 重なったとき、大きいほうを上に重ねる (寒い地方の中の、もっと寒い山頂)。同じなら階層の順 |

- 切ってある (自分か親が) エリアは使わない
- 3D のエリアは 3D の位置だけ、2D のエリアは 2D の位置だけに効く

### 計算 (純粋。`runtime/Climate.*`・テストあり)

1. エリアの中での深さ (一番近い縁までの距離。外は 0 以下) → 重み = なめらかな段 (0 で 0、境目の幅で 1)
2. 外の気候から始め、エリアを優先度の小さい順に、重みの分だけそのエリアの値へ寄せる
3. 3D: 気温から (高さ − 基準の高さ) ÷ 100 × 高さで冷える を引く

### スクリプト (`#include "RMClimate.h"`)

- `rm::Climate::TemperatureAt(rm::Vec3)` / `HumidityAt(rm::Vec3)` (3D)・`TemperatureAt2D(rm::Vec2)` / `HumidityAt2D(rm::Vec2)` (2D)
- `rm::Climate::SetTemperature(℃)` / `SetHumidity(%)` / `Temperature()` / `Humidity()` (シーンの設定 = エリアの外)
- 使い道: 寒さで体力が減る・吐く息が白い・水が凍る・NPC が上着を着る

### エディター

- シーンビューの「形」のスイッチ (選択 / 全部) で、エリアの縁と、境目の内側の縁を線で描く (物理のコライダーと同じ口 `kSceneLinesPoint`)
- 追加の部品のフォルダー「気候」

## 天候 × 気候 (段階 1-b)

- **天候の口** `rm_engine.weather.place` (`weather/runtime/WeatherPlace.h`): 「格子の点ごとの、雪の割合と降る量の倍率」。天候は答える者を知らない
- **粒ごとに決める**: 雨粒と雪の 1 粒ずつが、自分の場所の「雪になる割合」を見て、出るか消えるかを決める。境目では両方が混ざる (みぞれ)。割合はカメラのまわりの 7 x 7 の格子 (箱の一辺を 6 等分: 雨 4 m・雪 3 m ごと) で、シェーダーが線形に補間する。粒は倍率の一番大きい 1.5 倍のぶん用意して、場所で減らす
- **雪になる割合**: 気温 +2 ℃ で 0、−1 ℃ で 1 (間はなめらかに)
- **降る量の倍率**: 湿り気 50 % で 1、0 % で 0 (降らない)、100 % で 1.5
- **カメラのいる所の今の天候**: つなぎのシステム「天候 × 気候」(天候のシステムの前) が、Play の間ゲームのカメラの場所の割合と倍率を `Weather::placeSnow` / `placeMore` に、約 2 秒で 63 % ずつ近づけて書く。霧・濡れ・積雪はそれで決まる (エディターで Play していないときは書かないので、霧は「雪にする」のとおり)
- 「雪にする」のチェック: 気候があるときは使わない (そのツールチップに書いた)
- 濡れと積雪: 段階 1-b では、まだシーン全体で 1 つ (カメラのいる所の割合で進む)

## 段階

1. **段階 1-a** (2026-11-22 済み。版 0.0.7): 気候プラグイン (設定・エリア 2D / 3D・計算・スクリプト・枠の線・ヘルプ)。天候はまだ変わらない
2. **段階 1-b** (2026-11-22 済み。版 0.0.8): 天候 × 気候 (粒ごとの雨 / みぞれ / 雪・降る量・カメラのいる所の今の天候)
3. **段階 2**: 濡れと積雪を**場所ごと**に持つ (地面を真上から見たマス目の地図)。雪の所だけ積もり、雨の所だけ濡れる。境目で積雪が薄れる
4. **段階 3**: エリアが「自分の天気」を持てる (持たないエリアはシーンの天気のまま。両方を混ぜて使える)。エリアごとに天気が時間で変わる (天気予報)・`rm::Sky::WeatherAt(位置)`

## 決めていないこと

- 2D のシーンの雨と雪 (天候は今 3D だけ)。2D の気候は、今はスクリプトで読むだけ
- 気候エリアの形を、地形に塗る形 (地形ができてから)
