# 気候 (プラグイン「気候」と、つなぎ「天候 × 気候」)

同じシーンの中に、雨の降る所と雪の降る所を作る。マインクラフトのように「雪のエリアに入った瞬間に
雪」ではなく、ゼルダの伝説 ブレス オブ ザ ワイルドのように**土地の気候で降る物が決まり、境目では
少しずつ変わる**ようにする。

## 決まったこと (2026-11-22)

| 項目 | 決めたこと | 決めた人 |
|---|---|---|
| どこに作るか | 天候とは**別のプラグイン「気候」**。天候とは**つなぎ「天候 × 気候」**でつなぐ (今の「天候 × 物理」と同じ形) | ユーザー |
| 2D | 気候エリアは **2D のシーンでも**使える | ユーザー |
| 湿り気 | **気候の側**に持つ (天気以外にも使える: 砂漠の乾き・植物など) | ユーザー |
| 雨か雪か | エリアに「雨」「雪」を直接書かず、**気温で自動に決める** (+2 ℃ 以上は雨、-1 ℃ 以下は雪、間はみぞれ) | ユーザー (2026-11-22) |
| 気候は地図に塗る | **「気候」タブ**で、シーンを真上から見た地図 (マインクラフトの地図のような絵。ドットではない) に**ペンで塗った所がその気候になる**。天候も同じタブで変える。塗った気候は下の層で、気候エリアはその上に重なる | ユーザー (2026-11-24) |
| 気候ビュー | 今の「気候」タブを育てる (別のビューは作らない)。地図に**気温・湿り気・雲の量を色で見せる**。地帯は**筆で塗る**のと**ペンで囲む**のを両方使える (囲んだ形は後で点を動かして直せる)。**雲の量も地図に塗る** (空の雲はそこだけ厚く、雨や雪は雲のある所だけ降る) | ユーザー (2026-11-25) |
| インスペクターとタブ | インスペクターの「天候」と「気候」は、気候のタブで描いていない所**全部**に効く。タブで描いた所 (塗った・囲んだ) はそちらが勝つ。**高さで冷える**は共通 (描いた所にも効く) | ユーザー (2026-11-25) |
| 雪にする | 気候のプラグインが入っているとき (つなぎ「天候 × 気候」があるとき)、天候の「雪にする」は**インスペクターにも気候のタブにも出さない**。雨か雪かは気温と湿り気で決まるため (値はファイルに残る) | ユーザー (2026-11-25) |
| 雨は 2 通り | 雨 (雪) を**シーン全体**と**一部だけ**に分ける。シーン全体はシーンのインスペクターの天候の「降水量」。一部だけは、気候のタブの「**天候**」で**雨雲をペン (と筆) で描く**: 描いた所はシーンの降水量が 0 でも降る (雨か雪かは気温)。塗った雲 (雲の層) は雨を止めない (版 0.0.16 の「雲のある所だけ降る」はやめた) | ユーザー (2026-11-25) |
| 雨雲の濃さとぼかし | 雨雲は「**雨の濃さ**」(降る量。目安 ぽつぽつ 10 / 小雨 30 / 雨 60 / 大雨 85 / 嵐 100 か数) を選ぶ。**ペンで囲んだ雨雲は真ん中がその濃さで、縁に向かってなめらかに弱くなる** (「ぼかし」%: 縁から真ん中までのうち弱くなる幅。0 % で縁まで同じ)。**筆で塗った雨雲も同じ** (筆の円の真ん中が濃さ、縁へ弱く。重ねて塗ると濃いほう) | ユーザー (2026-11-26) |
| 雨雲は雨から | **雨を降らせる所には必ず雨雲を描き、雨雲の無い所には降らせない** (雨雲は降る量から作る: 塗った雲の量では決めない)。雨雲の濃さ・暗さ・厚みは**降る量に比例**: 小雨・天気雨は明るい薄い膜 (日が透ける)、どしゃぶり・嵐は黒ずんだ分厚い雲。シーン全体の雨 (降水量) も同じ | ユーザー (2026-11-26) |
| 道具のボタン | 気候のタブの「気候」と「天候」の両方で、筆・消しゴム・ペン・選ぶは**シーンビューの左上と同じ正方形のアイコンのボタン** (地図の左上に縦に並ぶ) で選ぶ | ユーザー (2026-11-25) |
| 空の天気 | **両方使えるようにする**。ふだんはシーンで 1 つ (雲・降水量・風・雷)。エリアに「自分の天気」を持たせると、その中ではそちらが勝つ (境目の幅でなめらかに混ぜる)。持たせないエリアはシーンの天気のまま、雨か雪かと降る量だけを気候で変える。エリアの天気は段階 3 | ユーザー (2026-11-22) |

## プラグインの形

| プラグイン | 前提 | 持つもの |
|---|---|---|
| **気候** `rm_engine/climate` | ゲーム制作・3D 空間・2D 空間 (物理と同じ: 1 つのプラグインで 2D と 3D の部品を持つ) | シーンの設定「気候」・部品「気候エリア」(3D) と「気候エリア 2D」・場所ごとの気温と湿り気の計算・スクリプト (`RMClimate.h`)・シーンビューのエリアの枠 |
| **天候** (今のもの) | 変わらない | 天候だけのときは今と同じ (「雪にする」でシーン全体が雨か雪) |
| **天候 × 気候** `rm_engine/weather_x_climate` (つなぎ・段階 1-b) | 天候・気候 | 天候の新しい口 (「この場所でどれだけ雪になるか・降る量の倍率」) に、気候の気温と湿り気から答える |

天候は気候を知らない (一般の口だけを持つ)。気候も天候を知らない。

## 気候の中身

### シーンの設定「気候」 (エリアの外の気候)

- **気温 (℃)**: 既定 15
- **湿り気 (%)**: 既定 50
- **高さで冷える (℃ / 100 m)**: 3D だけ。高い所ほど気温が下がる。既定 0.6 (本物の空気くらい)。山の上だけ雪、が自然にできる
- **基準の高さ (m)**: この高さで上の気温になる

設定が無いシーンも、既定の値の気候として答える。

### 部品「気候エリア」(3D) / 「気候エリア 2D」

| 項目 | 意味 |
|---|---|
| 形 | 3D: 箱 / 円柱 (縦が高さ)。2D: 長方形 / 円 |
| 大きさ (3D) / 広さ (2D) | Transform の大きさを掛ける。回転も付いてくる |
| 境目の幅 (m) | 縁からこの幅だけ内側へ、外の気候から中の気候へなめらかに変わる (0: 縁で切り替わる) |
| 気温を変える・気温 (℃) | 切ると気温はそのまま (湿り気だけ変えるエリア: 霧の谷など) |
| 湿り気を変える・湿り気 (%) | 切ると湿り気はそのまま |
| 優先度 | 重なったとき、大きいほうを上に重ねる (寒い地方の中の、もっと寒い山頂)。同じなら階層の順 |

- 切ってある (自分か親が) エリアは使わない
- 3D のエリアは 3D の位置だけ、2D のエリアは 2D の位置だけに効く

### 計算 (純粋。`runtime/Climate.*`・テストあり)

1. エリアの中での深さ (一番近い縁までの距離。外は 0 以下) → 重み = なめらかな段 (0 で 0、境目の幅で 1)
2. 外の気候から始め、エリアを優先度の小さい順に、重みの分だけそのエリアの値へ寄せる
3. 3D: 気温から (高さ − 基準の高さ) ÷ 100 × 高さで冷える を引く

### スクリプト (`#include "RMClimate.h"`)

- `rm::Climate::TemperatureAt(rm::Vec3)` / `HumidityAt(rm::Vec3)` (3D)・`TemperatureAt2D(rm::Vec2)` / `HumidityAt2D(rm::Vec2)` (2D)
- `rm::Climate::SetTemperature(℃)` / `SetHumidity(%)` / `Temperature()` / `Humidity()` (シーンの設定 = エリアの外)
- 使い道: 寒さで体力が減る・吐く息が白い・水が凍る・NPC が上着を着る

### エディター

- シーンビューの「形」のスイッチ (選択 / 全部) で、エリアの縁と、境目の内側の縁を線で描く (物理のコライダーと同じ口 `kSceneLinesPoint`)
- 追加の部品のフォルダー「気候」

## 気候の地図と「気候」タブ (2026-11-24)

気候を分かりやすく決めるための道。エリア (部品) を置いて大きさを合わせる代わりに、真上から見た地図に塗る。

### シーンの設定「気候の地図」(`ClimateMap`。3D のシーンだけ)

| 項目 | 意味 |
|---|---|
| 気候の種類 (`kinds`) | 名前・色 (地図に塗る色。ゲームには出ない)・気温 (℃)・湿り気 (%)。番号 (`id`) で見分ける (並べ替えても消してもほかのマスは変わらない)。新しい地図には 温帯 15 ℃ 50 % / 寒冷 -8 ℃ 60 % / 砂漠 32 ℃ 10 % / 熱帯 28 ℃ 85 % |
| マスの大きさ (`cellSize`) | ワールドに固定のマス目の一辺 (m)。既定 4。タブで 1 / 2 / 4 / 8 / 16 から選ぶ (変えると塗った所を同じ場所に塗り直す: `Resample`) |
| 地図の境目の幅 (`border`) | 塗った所の縁をはさんで、この幅でなめらかに変わる (m)。既定 8。0: マスの縁で切り替わる |
| 塗った所 (`cellX` / `cellZ` / `width` / `depth` / `cells`) | 塗った所だけを囲む長方形と、その中の種類の番号を行ごとに続けて読んだもの (z の小さい行から。0 = 塗っていない) を**ランレングス**で書いた文字 (`"0*12,2*5,3"`)。インスペクターには出さない (見せるのは境目の幅だけ。種類とマスの大きさはタブで変える)。長方形の一辺は 2048 マスまで |

- 保存は自己記述の JSON (シーンの `settings`)。知らないキーは書き戻す (テスト `Climate_PaintGrid`)
- 2D のシーンでは使わない (インスペクターにも出ない: `SceneSettingInfo::space = "3d"`)。2D の気候は今までどおり「気候エリア 2D」

### 計算 (純粋。`runtime/Climate.*`・テスト `Climate_PaintBlend`)

1. 外の気候 (シーンの「気候」) から始める
2. **地図** (下の層): その場所 (x, z) を真ん中にした一辺「境目の幅」の正方形の中で、それぞれの種類で塗った面積の割合 w を出し (箱フィルター)、気温 = Σ w × 種類の気温 + (1 − Σw) × 外の気温 (湿り気も同じ)。まっすぐな縁では、境目の幅の中でまっすぐ変わる
3. **気候エリア**: 今までどおり優先度の順に重ねる (湿り気を変えないエリアの中は、地図の湿り気のまま)
4. 3D: 高さで冷える

- 速さ: 面積は種類ごとの**積分画像** (summed-area table: 各点に「そこより左下のマスの数」を入れた表) を 4 か所引くだけで出す (マスの数によらない)。マスの中は塗りが一様なので、表の値を双線形に補うと端数の面積もちょうど出る (境目がマスの中でもなめらか)。表は地図の中身ごとに 1 回作り、同じ中身なら使い回す (`PaintTablesOf`。最近の 4 つ)。`ClimateField` は 1 コマに何度も作られる (天候 × 気候 の格子) が、表は作り直さない
- 天候 × 気候 は `ClimateField` に聞くので、塗った気候で雨 / みぞれ / 雪・降る量・濡れと積雪が自動で変わる (テスト `Climate_PaintWeather`)。スクリプトの `rm::Climate::TemperatureAt` も同じ

### 「気候」タブ (`editor/ClimateTab.*`。ゲーム制作の口 `rm_engine.game_production.view_panel`)

- 上の帯: 「気候」/「天候」の切り替えと「全体を見る」(エンティティ・気候エリア・塗った所が入るように)
- **地図の絵**: 気候はゲーム制作 × 3D を知らない (憲法 10) ので、口 `rm_engine.game_production.scene_view` の空間 `"3d"` のシーンビューを自分で 1 つ作り、`SceneViewHost::overhead` (真ん中と幅の半分) を渡して描かせる。3D のシーンビュー (`game_x_3d/editor/SceneView3D.cpp` の `DrawOverhead`) は、正射影でまっすぐ見下ろし (`Orthographic` + `LookAt(上の向き = +Z)`)、ゲームの見た目 (グリッド・ツール・ギズモ・印・選択の枠なし) で、空と天候の粒は描かない。**画面の右が +X、上が +Z** (左手系で上から見るので、+Z を下にすると鏡に映った絵になる。設計の案の「下が +Z」から変えた)。背景はテーマの色
- その上に: 塗った所 (種類の色で半透明。行ごとに同じ種類の続きを 1 つの四角に。縮めて 1 マスが 2 DIP より小さいときは何マスかおきに見る)・近いときはマス目の線・気候エリア (3D) の縁と境目の内側の縁 (シーンビューの枠と同じ線: `editor/ZoneLines.h`)・筆の輪
- 操作: 左ドラッグで塗る / 消す (前の場所から今の場所まで筆の半径の 3 割ごとに円を塗る。**離したときに Undo の 1 件**)・ホイールでカーソルの所を中心に拡大縮小・右 / 中ドラッグで動かす
- 右 (「気候」): 筆 / 消しゴム / ペン / 選ぶ (2026-11-25 から。下の「気候ビュー」)・描く層・筆の半径・マスの大きさ・気候の種類の一覧 (色見本・名前・℃・%)・＋ 足す / 消す・選んだ種類の値と地図の境目の幅 (インスペクターと同じ描き方: `editor::inspector::Draw`)
- 右 (「天候」): 気候の口 `rm_engine.climate.tab_page` (`editor/ClimatePages.h`) に差し出されたシーンの設定を、インスペクターと同じ描き方で (ゲーム制作の `SceneSettingLook` のテンプレートの行も)。天候は気候を知らず、気候も天候を知らないので、**つなぎ「天候 × 気候」のエディター側**が「天候」を差し出す
- 編集はどれも、変わったフィールドごとの `reflect::SetFieldCommand` (いくつも変わるときは 1 つの `CommandGroup`) を履歴に積む = Undo の 1 件 = 未保存 (憲法 7)。シーンの設定の場所は `SceneViewHost::setting` (ゲーム制作が渡す)。Play 中は塗れない・変えられない
- 見え方 (どこを見ているか・道具・筆の大きさ・選んだ種類) は `ClimateTabState` (パネルの配置と一緒に保存。プロジェクトには入れない)

## 気候ビュー (2026-11-25)

「気候」タブを、気候を見て・描くビューにする。

### 見る

- 地図の上の帯の「**見る**」: **塗り** (今までの、種類の色) / **気温** / **湿り気** / **雲**
- 気温・湿り気・雲は、地図の上に**色の段**で重ねる (寒い青〜暑い赤、乾いた黄〜湿った青緑、晴れの空色〜厚い雲の灰色)。右下に色と値の目盛り。値は `ClimateField` が答えるもの (塗った気候・ペンの形・気候エリア・境目の幅を全部入れたもの。気温は「基準の高さ」での値)。カーソルの所の値も出す
- 雲の色は、地図に塗った所だけ (塗った割合の濃さで)。塗っていない所は色を付けない (シーンの天気の雲のまま。気候は天候を知らないので、その量は地図に出さない)

### 描く: 道具と層

- 道具: **筆** (今までの「ペン」: 丸い筆でマスを塗る) / **消しゴム** / **ペン** (線で囲む) / **選ぶ** (囲んだ形を直す)
- 描く**層**: **気候** (種類を塗る) / **雲** (雲の量を塗る。右の欄の「雲の量 (%)」の値で塗る)
- **ペン**: 地図をクリックするごとに点を置き、押したままドラッグすると線をなぞって点を置く (手描き)。最初の点をクリック・ダブルクリック・Enter で閉じて形になる (3 点から)。Esc でやめる。閉じた形の中のマスが、その層の値になる (気候: 選んだ種類 / 雲: 雲の量)。1 つの形が Undo の 1 件
- **選ぶ**: 形をクリックで選ぶ (点が出る)。点をドラッグで動かす・形の中をドラッグで形ごと動かす・点を右クリックで消す (3 点は残す)・Delete で形を消す。選んだ形の値 (種類・雲の量) を右の欄で変えられる。1 回のドラッグが Undo の 1 件
- 重なり: 下から **筆で塗ったマス → 形 (並びの順。あとで描いたものが上)**。消しゴムは筆のマスだけを消す (形は「選ぶ」で消す)
- 「雪にする」を隠す口: ゲーム制作の `kSceneSettingHidePoint` (`SceneSettingLook.h` の `SceneSettingHide`)。つなぎ「天候 × 気候」のエディター側が天候の `snowing` を足す。シーンのインスペクターと気候のタブの「天候」が `HiddenSettingFields` でその欄を出さない (インスペクターの `Block::hidden`)。天候も気候も互いを知らないまま

### データ (シーンの設定「気候の地図」に足す)

| 項目 | 意味 |
|---|---|
| 形 (`shapes`) | `ClimateShape`: 層 (`layer`: 0 気候 / 1 雲 / 2 雨雲)・種類 (`kind`。気候の層)・雲の量 (`clouds` %。雲の層)・降る量 (`rain` %。雨雲の層。形の真ん中の濃さ)・ぼかし (`soft` %。雨雲の層。既定 100)・点 (`points`: ワールドの x, z。4096 点まで)。インスペクターには出さない |
| 雲の塗り (`cloudX` / `cloudZ` / `cloudWidth` / `cloudDepth` / `cloudCells`) | 気候の塗りと同じマス目・同じランレングス。値は 雲の量 + 1 (0 = 塗っていない) |
| 雨雲の塗り (`rainX` / `rainZ` / `rainWidth` / `rainDepth` / `rainCells`) | 同じ。値は 降る量 + 1 (降る量の目盛りは天候の降水量と同じ: 10 ぽつぽつ 〜 60 雨 〜 100 嵐) |

- 種類を消すと、その種類の形も消える。マスの大きさを変えても、形はそのまま (点はワールドの場所)
- 形は計算の前にマス目に**焼く** (マスの真ん中が形の中ならそのマス: 偶奇の規則)。計算は今までどおり塗ったマスの表だけを引く (式は 1 つ)。焼いた結果は地図の中身ごとに 1 回 (`PaintTablesOf` の使い回しに形も入れる)

### 雲の計算 (純粋。`runtime/Climate.*`)

- 気候と同じ箱フィルター (一辺「地図の境目の幅」): その場所のまわりの、雲を塗った面積の割合 w と、塗った所の雲の量の平均 a を出す (`ClimateHere::cloudWeight` / `cloudAmount`)
- その場所の雲の量 = (1 − w) × シーンの雲の量 + w × a。気候は天候を知らないので、混ぜるのはつなぎ (天候 × 気候)
- 表は気候の種類と同じ積分画像 (塗った数と、雲の量の和の 2 つ)
- 雨雲も同じ式・同じ表の作り方 (`PaintTables::AmountLayer`。雲と雨雲で 1 本): まわりの雨雲の割合 (`rainWeight`) と降る量の平均 (`rainAmount`)。一番多い降る量 (`MostRain`) も地図ごとに 1 回数える

### 天候 × 気候 がすること

- **雨は 2 通り** (版 0.0.17 から): シーン全体は天候の「降水量」(湿り気の倍率つき)。一部だけは描いた雨雲: 天候の口の `WeatherPlace::local` (その場所だけ降る量 = 雨雲の割合 × 降る量 / 100) に答え、天候は**その場所で降る量 = max(降水量 × 倍率, local)** にする (`weather::PlacedShare`。粒・カメラの所の今の天候・濡れと積雪の地図が全部これを通る)。雨か雪かは今までどおりその場所の気温。粒は「降水量 × 1.5」と「シーンの雨雲の一番多い降る量」(口の `mostLocal`) の多いほうだけ用意して、場所で減らす
- 版 0.0.16 の「雨と雪は雲のある所だけ」(雲の量 30 〜 60 % の段) はやめた: シーン全体の雨は、雲を薄く塗った所にも降る (ユーザーの決定: シーン全体はインスペクター、一部は雨雲)
- **雨雲の空** (版 0.0.19 から。前の `RainCloudsOf` / `MixRainClouds` (雨雲の所の雲の量を 70 〜 100 % にする) はやめた): 空の地図はマスごとに「雲の量」と「**降る量**」を持ち、地球の空のシェーダーは降る量の所に**雨雲の層** (塗った雲の層の下の、低い 1 枚) を描く。不透明さ・暗さ・厚みはどれも降る量に比例: 不透明さ = smoothstep(0, 0.12, 降る量) × (0.25 + 0.75 × 降る量)、厚み = smoothstep(0.15, 0.95, 降る量) で明るい膜の色から黒ずんだ底の色へ、厚いほど もくもくしたむら (ノイズ) と地平線の下まで続く層。雪の雲は淡い。マスの降る量 = max(シーン全体の降る量, その場所だけ降る量)。粒と同じ値から作るので、**雨の降る所には雨雲があり、雨雲の無い所には降らない**
- **空全体の暗さはシーン全体の天気** (版 0.0.19 から): 空の色の暗さ・雲の模様の量・雷はシーン全体の天気 (`NowOf(w, false)`: カメラのいる所の塗った雲・その場所だけ降る量を入れない)。カメラが雨雲に入っても空全体は暗くならない (真上の雨雲が暗い)。日の光の弱まりともやはカメラのいる所のまま
- **雨雲の形のぼかし** (版 0.0.18 から): 雨雲の層の形は `FillShapeSoft` で焼く。中のマスごとに「形の外の一番近いマスまでの距離」を距離変換 (行ごとの横の距離 → 列ごとに放物線の下側の包み: Felzenszwalb と Huttenlocher。マスの数に比例) で出し、縁からの距離 = それ − 半マス。一番遠いマスまでの距離 × ぼかし より内側は濃さのまま、その外は smoothstep で縁へ薄くする。1 % より薄いマスは塗らない。重なった所 (ほかの形・筆の塗り) は**濃いほう** (気候と雲の形はこれまでどおり上書き)。焼くのは `BakeShape` 1 本 (計算・地図の絵・塗っている途中の絵が同じ)
- **雨雲の筆のぼかし**: 雨雲の層の筆は `PaintCircleSoft`。押した所 (ドラッグでは半径の 3 割ごと) の円の中のマスを、真ん中からの距離で同じ曲線 (`SoftFade`) で薄くし、今のマスより濃い所だけ書く。なので線を引くと、線の真ん中が濃く、両側へ薄くなる。薄くするのは消しゴム
- 雨粒はカメラのまわり (24 m の箱) にしか描かないので、離れた雨雲の下に降る雨の柱は見えない (空の厚い雲は見える)。雨雲の中に入ると降る
- **カメラのいる所の雲** (Play の間): 塗った割合と雲の量を `Weather::placeCloudShare` / `placeClouds` に、約 2 秒で 63 % ずつ近づけて書く。天候の `TargetOf` が、天気の雲の量を割合の分だけその量へ寄せる。空の暗さ・日の光の弱まり・雲の厚さはこれで決まる。雲を塗っていない地図では書かない (`placeClouds` = -1: 今までどおり)
- **雲の地図** (版 0.0.19 から 128 x 128 マス・1 マス 24 m: 3 km 四方ほど。前は 48 x 48・64 m): 天候の口 `WeatherPlaceInfo::clouds` に、つなぎが**空を描くたびに**答える (エディターのシーンビューでも。前は Play の間だけ `Weather::cloudShares` / `cloudCells` に書いていた): マスの真ん中のまわり 1 マス四方の、雲を塗った割合・塗った雲の量・その場所だけ降る量 (`weather::PlaceClouds`)。天候 (`SkyWeatherOf`) がマスごとの雲の量 (シーンの雲の量から塗った割合の分だけ塗った量へ) と降る量にして空に渡す。塗っていないマスはシーン全体の値そのものなので、地図の無い空と 1 ピクセルも変わらない
- **空の絵 (雲の地図の読み方。`space3d/runtime/SkyShader.*` の `CloudMapAt` と地球の空の `CloudsHere`。テスト `tests/TestSkyClouds.cpp`)**:
  - **雲の層**: カメラの **600 m 上**の水平な面 (`space3d::kCloudLayerHeight`)。向き d がその面と交わる所 = カメラの x, z + d.xz × (600 / d.y)。その場所の地図のマスを、マスの真ん中の間で線形に補間して読む (地図の外は端のマス)
  - **混ぜ方**: その向きの (雲の量, 降る量) = 地図の値と、シーン全体の値 (`param[1].x` / `param[7].x`) を、地図の縁へ向かう薄れで混ぜたもの (`CloudsHere`)。雲の量は雲の模様の濃さと厚い層 (75 % から)、降る量は雨雲の層を決める
  - **薄れ**: 交わる所が地図の真ん中から縁までの **7 割** (`space3d::kCloudFadeFrom`) を越えると薄れはじめ、縁で 0 (地図の外は一様な雲の量)。地平線の近くは交わる所が遠い (600 m の層、地図の半分 1536 m では、高さ約 21 度より下は地図の外) ので、地平線に筋が出ず、今までの雲につながる。地平線より下も一様なまま
  - **送り方**: 天候が `SkyWeather` の雲の地図 (割合・量・最初のマスの真ん中・マスの大きさ) に入れ、空の見た目 (`LookOf`) が 0 .. 1 にそろえて `SkyLook::clouds` と `param[6]` に、描き手 (`SkyPainter`) が `SkyDraw::clouds` に渡す。レンダラーは毎フレーム 48 x 48 の `R32G32_FLOAT` の絵 (r: 割合、g: 量) にして t6 に結ぶ。空のシェーダーはカメラの場所を `SkyInput::eye` で読む
  - **地図が無いとき** (気候が無い・Play していない): 今までと 1 ピクセルも変わらない (テスト `Sky_CloudMapOnGpu`)

## 天候 × 気候 (段階 1-b)

- **天候の口** `rm_engine.weather.place` (`weather/runtime/WeatherPlace.h`): 「格子の点ごとの、雪の割合と降る量の倍率」。天候は答える者を知らない
- **粒ごとに決める**: 雨粒と雪の 1 粒ずつが、自分の場所の「雪になる割合」を見て、出るか消えるかを決める。境目では両方が混ざる (みぞれ)。割合はカメラのまわりの 7 x 7 の格子 (箱の一辺を 6 等分: 雨 4 m・雪 3 m ごと) で、シェーダーが線形に補間する。粒は倍率の一番大きい 1.5 倍のぶん用意して、場所で減らす
- **雪になる割合**: 気温 +2 ℃ で 0、−1 ℃ で 1 (間はなめらかに)
- **降る量の倍率**: 湿り気 50 % で 1、0 % で 0 (降らない)、100 % で 1.5
- **カメラのいる所の今の天候**: つなぎのシステム「天候 × 気候」(天候のシステムの前) が、Play の間ゲームのカメラの場所の割合と倍率を `Weather::placeSnow` / `placeMore` に、約 2 秒で 63 % ずつ近づけて書く。霧・濡れ・積雪はそれで決まる (エディターで Play していないときは書かないので、霧は「雪にする」のとおり)
- 「雪にする」のチェック: 気候があるときは使わない (そのツールチップに書いた)
- 濡れと積雪: 段階 1-b では、まだシーン全体で 1 つ (カメラのいる所の割合で進む)。段階 2 で場所ごと (下)

## 場所ごとの濡れと積雪 (段階 2)

- **地図**: 地面を真上から見たマス目。**カメラのまわり 128 m 四方を 64 x 64 マス (1 マス 2 m)** (`weather::kWetMapCells` / `kWetMapCell`。`Weather::wetMap`)。シーン全体にしないのは、シーンの広さが決まっていないため (広い地形でも同じ重さで済む)。2 m は、気候エリアの境目の幅 (ふつう数 m〜数十 m) をなめらかに描ける細かさ
- **マスが持つもの**: 濡れの向き (`WetWay`: 雨と雪の降った向き。最大 4 つ。向きとしみこみはシーン全体で共通) ごとの、日なたの濡れ・日陰の濡れ・積雪の深さ (`WetLevel`)
- **マスはワールドに固定**: カメラが 1 マス動くと地図がずれる。新しく入るマスは**地図の一番近いマスの値**で始まる (いきなり乾いた帯が出ない)。地図の外も、描くときは一番近いマス。Play の最初は乾いて雪なし
- **進め方** (純粋。`Weather.cpp` の `StepWetMap`。テスト `Weather_WetMap` / `Weather_WetMapRun` / `Climate_WeatherPlace`): マスごとに、口の降り方 (雪の割合と降る量) でそのマスの雨と雪を決め、シーン全体で 1 つのときと**同じ式** (`StepLevels`。`StepWet` もこれを使う) で進める。だから雪の所だけ積もり、雨の所だけ濡れ、雨の所の雪は溶ける。向きは「どこかで降っているもの」で作り、全部のマスで乾いたら消す。どこでも同じ降り方なら、シーン全体で 1 つのときとまったく同じになる (テストで確かめる)
- **誰が書くか**: つなぎのシステム「天候 × 気候」が、毎フレーム地図のマスの真ん中の降り方を口の `grid` で聞いて `Weather::placeCells` に書く (`weather::PlaceCellsFor`)。天候のシステムはそれを使って地図を進め、使ったら空にする。**書く者がいない (気候が無い) フレームは地図を捨て、今までどおりシーン全体で 1 つ**
- **高さ**: マスの気温はカメラの高さで聞く (粒の格子と同じ)。だから「山の上だけ雪」は、カメラが山の上にいるときに山の上で積もる。地面の高さで聞くのは、地形ができてから (下の「決めていないこと」)
- **描き方**: 地図をテクスチャ (幅 3 x 64・高さ 64、`R32G32B32A32_FLOAT`。左から日なた・日陰・積雪のブロック、1 テクセルに向き 4 つ) にして毎フレーム送る。3D 空間の「面の塗りに足す口」に絵を 1 枚渡せるようにした (`SurfaceTouch::texture`、t10)。面のシェーダーと積もった雪の層の頂点シェーダーが、場所の値を**マスの真ん中の間で線形に補間**して読む (`WetPlace`) ので、境目で濡れも積雪もなめらかに薄れる
- **スクリプト** (`rm::Sky::Wetness` / 積雪の深さ): カメラのいるマスの値
- **一時停止と Play の終わり**: 時間の速さ 0 では進まない (dt 0)。Play を止めると消える (今までどおり: 数えていないときは見せない)

## 決めていないこと

- 2D のシーンの雨と雪 (天候は今 3D だけ)。2D の気候は、今はスクリプトで読むだけ
- 濡れと積雪の地図のマスの気温を、地面の高さで聞く (今はカメラの高さ。地形ができてから)
- 地図の外 (カメラから 64 m より先) の濡れと積雪は、一番近いマスのまま。遠くまで見える広い景色で足りなければ、地図を 2 段 (近くは細かく、遠くは粗く) にする
- 気候エリアの形を、地形に塗る形 (地形ができてから)
- 2D のシーンの気候の地図 (今は 3D だけ。2D は気候エリア 2D)
- 地図の塗り方を増やす (塗りつぶし・四角・ぼかしの筆・ほかの種類の上だけ塗る)
