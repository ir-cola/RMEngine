- 機能を足したら、その試すことをここに足す (細かい手順は [HOW_TO_TRY.md](HOW_TO_TRY.md) の章に書き、ここには 1 行と章の番号だけ)
- 試したら `[x]` にして、日付と結果を書く。おかしかったものは直してから、もう一度ここに載せる
- 「**人が要る**」は computer use では確かめられないもの (耳で聞く・ゲームパッド・別の PC など)。ユーザーに頼む
