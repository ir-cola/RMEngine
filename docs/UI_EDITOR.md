# UI を作る画面 (UI タブを育てる) の設計 (2026-11-16)

ユーザーの要望: UI を細かく調整したい。今はキャンバスを置いてインスペクターだけで設定しているので、UI 専用の画面で
ギズモで操作し、キャンバスを複数作って瞬時に切り替え、動きを付けたい。

参考: 前のエンジンの仕様書 `TestEngine/UIウィンドウ仕様.txt` (2026-11-16。「仕様」と「★変える」を分けて書いてある)。
今の新エンジンのゲーム UI は [ARCHITECTURE.md](ARCHITECTURE.md) の「ゲーム UI」。

## 0. ユーザーが決めたこと (2026-11-16)

| 項目 | 決定 |
|---|---|
| 画面の形 | **今の「UI」タブを大きく育てる** (ゲーム制作のタブのまま。別ウィンドウにも出せる)。別のソフト「UI デザイン」にはしない |
| ギズモ | **移動・大きさ・回転** (回す中心も)・**吸い付きと揃え** (補助線・左揃え・等間隔)・**アンカーを絵で選ぶ** (16 種)・**親子と重なり順** (画面の中のドラッグで) |
| キャンバスの切り替え | **ゲーム中に切り替える**。ボタンを押したらポーズの画面を出す、などを**配置と配線** (スクリプトを書かずに) で決める |
| 動き | **出る・消えるときの動き** (トゥイーン)・**乗った・押したときの動き** (なめらかに)・**道 (パス) に沿って動く**。キーフレームのタイムラインは作らない |

## 1. 前のエンジンの仕様と、今の新エンジン

## 2. 作る順番 (案)

### UI-1 UI タブのギズモと編集 (ユーザーの決定のギズモ全部)

- **道具の帯**: 選ぶ・動かす・回す・大きさの切り替え (シーンビューと同じ W / E / R)・格子に吸い付く (刻み)・補助線に吸い付く・拡大率・「ゲームを後ろに重ねる」
- **拡大・平行移動**: ホイールで拡大 (マウスの位置を中心に)・中 / 右ドラッグで動かす (動いたら右クリックのメニューを出さない: 仕様 §9-2)・F で選んだ物に寄せる
- **8 つのハンドル** (角と辺) で大きさ・**外の輪で回転**・**回す中心 (pivot) を動かす印**。回した物の大きさも、その物の向きで (見えている四角で計算して戻す: 仕様 §1-2)
- **吸い付き**: 格子 (刻み)・ほかの物の端と真ん中・親の端と真ん中 (スマートガイド)。補助線を出す。Alt で吸い付かない
- **複数を選ぶ**: Shift / Ctrl クリック・空いた所からの四角で囲む。一緒に動かす / 大きさ。**揃え** (左・真ん中・右・上・中・下) と**等間隔**の帯
- **アンカーを絵で選ぶ**: 4 × 4 の図 (Unity と同じ)。Shift で中心も、Alt で位置も合わせる (アンカーを変えても場所を保つ: 2026-11-16 の `Reanchored`)
- **親子と重なり順**: UI タブの左に「このキャンバスの中の物」の小さな一覧 (ドラッグで親と順番)。画面の中でも、物を別の物の上へ Ctrl+ドラッグで親を変える
- **キャンバスの切り替え**: 帯にキャンバスの一覧 (編集する 1 枚を選ぶ。ほかのキャンバスを薄く重ねて見る / 見ない)。右クリックで「キャンバスを作る」
- ダブルクリックで文字を直接編集・アセットのパネルから画像をドラッグで置く (その場所に「画像」)
- どれも Undo 1 回分 (ドラッグは 1 回分)。純粋な計算 (ハンドルの数式・吸い付き・揃え) は `UiLayout` に足してテスト

### UI-2 ボタンの見た目と動き (乗った・押したとき)

- **状態の補間** (秒): 色・大きさ・縁を、指数でなめらかに (フレームの速さに依らない: 仕様 §6-6)。既定は恒等 (ボタンでない物は 1 ビットも変わらない)
- 見た目の軸を足す: **縁** (太さと色。混ぜる先は自分の枠: 仕様 §6-5)・**画像の差し替え**・**色の置き換え** (乗算では明るくできない: 仕様 §6-2)
- **乗ったとき・押したときの音** (音のプラグインがあれば。つなぎ)

### UI-3 押したときの動作 (配置と配線。スクリプトを書かずに)

- ボタンの部品に「押したときの動作」の一覧: **ウィンドウ (キャンバス) を出す / 隠す / 切り替える / 戻る**・シーンを切り替える・**グローバル変数**を変える (ON / OFF / 反転・足す / 入れる・上限下限)・ゲームを終わる・音を鳴らす
- 順番は 仕様 §6-6 と同じ (音 → 動作 → スクリプトの OnClick)。動作は Play とゲームの中だけ
- **コントローラーで選ぶボタンの移る先** (上下左右の配線) もここで決める ― ユーザーの説明を待っている「配置と配線」と同じ画面にする

### UI-4 出る・消えるときの動き・道に沿って動く

- キャンバス (ウィンドウ) と UI の物に「**出るとき**」「**消えるとき**」の動き: フェード・すべり込む (向き)・大きくなる / 小さくなる・回る、の組み合わせ。長さ・待ち・**速さの曲線** (直線・ゆっくり始まる / 終わる・はねる・行き過ぎて戻る)。キャンバスを出す / 隠す (UI-3 の動作・スクリプトの Show) と、ゲームの始めに使う
- **パス**: UI タブで点を置いて線 (直線 / なめらか) を描き、物をその上で動かす (速さ・くり返し・往復・向きを合わせる)。部品「パスで動く」
- スクリプト: `rm::UI::MoveTo / ScaleTo / RotateTo / FadeTo` (仕様 §14)

### UI-5 見た目の追加 (仕様書の §2 から。要るものを選んでもらう)

背景の色と角丸 / 枠 / 影 (ぼかし) / 光 (Glow) / ぼかし / 立体 (ベベル) / 画像の切り出し / 字間・行の高さ・縦書き・部分スタイル /
虹色 / 動画。ぼかしと光は GPU で焼いてキャッシュ (仕様 §4: 鍵に「中身の ID」を使う)。

## 3. 前のエンジンから守ること (仕様書より)

- 描くコードは 1 本・描く先は引数 (今の `UiRenderer` のまま)
- 動いている間の値の既定は恒等 (乗算 1・大きさ 1・量 0)
- 当たり判定に入れないもの: ボタンの拡縮・文字だけのずらし (見た目だけ)。回転は入れる (新エンジンでは見た目どおり)
- 掴んでいる間は Undo / Redo をしない (仕様 §11-4)
- 「既定に戻す」で動作の一覧を消さない (仕様 §6-3)
- 範囲・式・述語は 1 か所 (`RM_PROPERTY` と `UiLayout`)

## 4. 決まったこと・決めていないこと

- 順番 (2026-11-16 ユーザー): **UI-1 → UI-2 → UI-3 → UI-4 → UI-5** (案のまま)
- UI-5 で要るもの (2026-11-16 ユーザー): **全部** (背景・角丸・枠・影 / 光・ぼかし・立体 / 文字の追加 / 虹色・動画・切り出し)
- まだ: 「配置と配線」の画面の形 (コントローラーの説明と一緒に)
