✅ 現在実装済みの機能一覧

  エンジン基盤
  - Win32 ウィンドウ管理（リサイズ・最大化・固定サイズ切替）
  - DirectX 11 デバイス・スワップチェーン・レンダーターゲット管理
  - アプリケーションループ（OnInit / OnUpdate / OnRender / OnShutdown）
  - タイマー（FPS計測・DeltaTime）
  - Win32 ドラッグ&ドロップ（ファイルパス受取）
  - DWM Windows 11スタイル（角丸・ボーダー）

  Hub画面
  - プロジェクト一覧（Name / Modified / Path 列、クリックソート昇降順）
  - 新規プロジェクト作成 / 既存プロジェクトを開く / オプション / ヘルプ ボタン
  - ... ポップアップ（エクスプローラーで開く / 名前変更モーダル / 削除確認モーダル）
  - パッチノート表示（バージョン一覧 + 詳細、Debug=ファイル読込 / Release=RCDATAリソース埋込）
  - ロゴ・アイコン表示（Logo.png / NewProject.png / Folder.png / Option.png / Help.png）
  - Hub固定サイズ（1280×720、リサイズ不可・最大化不可）
  - EditorウィンドウはHubからプロジェクトを開いたときのみ起動
  - Editor終了時にHubへ戻る

  Editor / ウィンドウ管理
  - Hub/Editor ウィンドウ分離（SetHubMode切替、deferred pattern）
  - Editor起動時 SW_SHOWMAXIMIZEDで最大化
  - Editor終了時の未保存確認ポップアップ（セーブして閉じる / セーブせずに閉じる / キャンセル）
  - m_isDirty フラグ（PushUndo時にセット、保存時にクリア）

  ImGui Docking レイアウト
  - フルスクリーンDockspace
  - 初回フレームのみ自動レイアウト確定（SetupDockLayout）
    - 下部23%: Console / Assets タブ
    - 左18%: Hierarchy
    - 右27%: Inspector
    - 中央: Scene
  - パネル表示/非表示（Windowメニュー + × ボタン）

  メニューバー
  - Object: Empty / 3D Object（8種） / 2D Object（2種） / UI（Image/Video） / Light（3種） / Camera
  - Edit: Add Scene（Plain / From Template）
  - Window: 全パネルのチェックマーク切替（Hierarchy / Scenes / Scene / Game / Inspector / Console / Assets）
  - Undo/Redoボタン（PNG アイコン付き ImageButton）

  ECS（Entity Component System）
  - CreateEntity / DestroyEntity / IsAlive
  - AddComponent / GetComponent / HasComponent / RemoveComponent / ForEach
  - ComponentPool（swap-remove方式、型消去パターン）

  シーン管理
  - 複数シーン保持（vector<SceneEntry>）
  - AddNewScene / SetActiveScene / DeleteScene
  - シーンテンプレートシステム（Save as Template / From Template）
  - 組み込み"Default"テンプレート（Plane + Main Camera + Directional Light）
  - プロジェクト起動時にDefaultテンプレート自動適用
  - シーン追加・削除のUndo/Redo対応（SceneCreateCmd / SceneDeleteCmd）
  - Deleteキーでアクティブシーン削除（2シーン以上のとき）

  Hierarchyパネル
  - TreeViewエンティティ表示（接続線付き）
  - 右クリックメニュー（Add / Copy / Paste / Detach from Parent / Delete）
  - 親子関係（ParentComponent）
  - ドラッグ&ドロップでリペアレント
  - 挿入ゾーン（2px）でノード間並び替え
  - SiblingOrderComponentによるルートエンティティソート
  - Deleteキーで選択エンティティ削除
  - "Anim Keyframe" タブ（アニメーションタイムライン）

  Inspectorパネル
  - オブジェクト名入力
  - Tag / Layer ドロップダウン
  - Transform（Position / Rotation / Scale）カスタムスライダー
  - Light セクション（Directional/Point/Spot、Brightness/Color/Range/SpotAngle）
  - Camera セクション（FoV / Near / Far）
  - Color & Texture セクション（カラースウォッチ・スライダー・テクスチャプレビュー・DnD・Browse）
  - Rigidbody / Attractor / Collider 追加可能コンポーネント（×ボタンで削除）
  - Add Component ボタン
  - DrawSmartSlider（完全カスタム実装：デルタドラッグ・動的レンジ・右クリックドラッグ・Lockボタン）
  - Undo/Redo対応（Transform / Color / Light / TexturePath / Name / Component追加削除）
  - "Anim Inspector" タブ（選択ボーンのPosition/Rotation InputFloat編集）

  SceneView
  - オフスクリーンレンダーターゲット
  - カメラ操作（右ドラッグ=オービット・ホイール=ズーム）
  - 左クリックレイピッキング（AABB/球交差テスト）
  - カメラ・ライトエンティティのスクリーンスペース距離ピック
  - ギズモツール（Select / Move / Rotate / Scale）、Q/W/E/Rショートカット
  - Grid Snap（間隔設定付き）
  - カメラアイコンビルボード（Camera.png）+ FOVフラスタム3Dワイヤーフレーム
  - ライトアイコンビルボード（Light.png）
  - コライダーワイヤーフレーム可視化（Box/Sphere/Capsule/Cylinder/Mesh、シアン/黄色）
  - ボーンスケルトン表示（選択中3Dモデルで常時表示）
  - Bone Modeトグル（選択ボーン操作パネル）
  - アセットファイルDnD（.objモデル追加）

  グラフィックス（3D）
  - Renderer3D（HLSL埋め込み、マルチマテリアル描画）
  - メッシュ形状: Cube / Sphere / Plane / Capsule / Cylinder / TriPrism / Cone / TriangularPyramid / Sprite2D / Circle2D / UIImage
  - OBJ / PMX / PMD モデル読み込み（tinyobjloader・独自パーサー）
  - マルチマテリアル（subMeshes）・テクスチャ自動読み込み
  - 多光源ライティング（最大8光源、HLSL CalcLight）
  - シャドウマップ（Directional/Spot=2D、Point=キューブ）、輝度比率方式合成
  - グリッド描画
  - ワイヤーフレームAPI（Box/Sphere/Capsule/Cylinder/Frustum）

  グラフィックス（2D・UI）
  - Renderer2D（スプライトバッチ）
  - UIImage（深度テスト無効、常時最前面）
  - UI Viewパネル（1920×1080、アスペクト比維持キャンバス）

  ボーン・アニメーション
  - PMX/PMDボーン読み込み（7種類分類: Rotation/RotationTranslation/IK/IKTarget/IKLink/AppendRotation/AppendTranslation）
  - VMDアニメーション読み込み（v1/v2対応、Z軸反転・Shift-JIS変換）
  - FK（Forward Kinematics）ボーン位置計算
  - CCD IKソルバー
  - PMX CPUスキニング（BDEF1/2/4対応、動的頂点バッファ）
  - アニメーションタイムライン（ボーングループ分類・キーフレームダイヤモンド表示）
  - キーフレーム登録/削除/コラム選択/全選択
  - VMDインポート・エクスポート
  - 表情差分パネル（モーフスライダー）
  - タイムライン縦スクロール
  - Animation Keyframeタブ (Hierarchyエリア内)
  - Animation Inspectorタブ (Inspectorエリア内、ボーンPos/Rot編集)

  物理演算
  - 重力・引力・AttractorAsDown（Slerpによる引力方向整列）
  - AABB衝突 → OBB衝突（坂転がり対応）
  - 球コライダー転がり摩擦（角速度・慣性維持）
  - 複数コライダー形状（Box/Sphere/Plane薄型/Capsule近似/Cylinder近似/Mesh AABB）
  - Play/Stop（スナップショット保存・復元）

  入力
  - キー入力 / マウス入力
  - Raw Inputマウス（ウィンドウ外・別モニター対応）

  Consoleパネル
  - Log / Warn / Error フィルタ（件数表示付き）
  - タイムスタンプ
  - 検索ボックス / Auto Scroll

  Assetsパネル（ExplorerPanel）
  - グリッドアイコン表示（64px）
  - サムネイル遅延ロード・キャッシュ
  - ドラッグ&ドロップ（ASSET_FILEペイロード）
  - ブレッドクラムナビゲーション（Assets外への移動禁止）
  - 外部ファイル自動コピー（拡張子で Sprite/Sound/Shader/Script/3Dmodel/movie/Other に分類）
  - ラベル自動改行・行高さ統一
  - Backボタン（Back.pngアイコン）

  Undo/Redo
  - ICommand インターフェース
  - TransformCmd / ColorCmd / LightCmd / TextureCmd / NameCmd / ComponentCmd<T>
  - SceneCreateCmd / SceneDeleteCmd / EntityCreateCmd / EntityDeleteCmd
  - Ctrl+Z / Ctrl+Y ショートカット

  プロジェクト保存
  - .tepファイル形式（v2）
  - Canvas / SiblingOrder対応
