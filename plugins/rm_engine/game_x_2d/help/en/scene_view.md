# Scene view (2D)

The panel where you look at a 2D scene and select and move things.

| Input | What it does |
|---|---|
| Right / middle drag | Pan |
| Wheel | Zoom in / out |
| Click | Select (Ctrl: add / remove) |
| Drag from an empty spot | Box select |
| Drag a thing | Move it |
| F | Frame the selection |
| W / E / R | Move, rotate, scale |
| X | Local / world |
| Z | Each / center |
| Ctrl + drag | Move in steps |
| Esc | Cancel the drag |

> Entities with a Transform 2D show up here as small rings. Add a sprite component to draw its picture (a white square when there is no image).
