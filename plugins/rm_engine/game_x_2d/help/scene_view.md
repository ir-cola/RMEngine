# シーンビュー (2D)

2D のシーンを見て、物を選んで動かすパネルです。

| 操作 | すること |
|---|---|
| 右 / 中ドラッグ | 平行移動 |
| ホイール | 近づく / 離れる |
| クリック | 選ぶ (Ctrl: 足す・外す) |
| 何も無い所からドラッグ | 四角で囲んで選ぶ |
| 物をドラッグ | 動かす |
| F | 選んだ物へ |
| W / E / R | 移動・回転・拡大縮小 |
| X | ローカル / ワールド |
| Z | それぞれ / 中心 |
| Ctrl + ドラッグ | 刻んで動かす |
| Esc | ドラッグをやめる |

> Transform 2D の付いたエンティティが、ここに小さな輪で出ます。スプライトの部品を付けると、その絵 (画像が無いときは白い四角) で描きます。
