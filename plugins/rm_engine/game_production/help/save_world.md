# 世界のセーブ

物の位置や状態をセーブして、あとで戻せます。グローバル変数のセーブと同じファイル (スロット) に入ります。

## 残す物を選ぶ
- 残したい物に部品「**セーブする**」を付けます (部品を足す ▸ ゲーム)。付けていない物は何も残りません
- 「位置・回転・大きさ」: 3D の Transform・Transform 2D の値と、親
- 「有効」: 有効かどうか
- 「全部の部品の値」: スクリプトも含めた全部の部品の値と、名前・タグ・レイヤー。ゲームの中で足した部品も足し直します
- Prefab に付けておくと、ゲームの中で作った物 (`rm::Spawn`) も残り、読むと作り直されます

## セーブと読み込み
- スクリプトから `rm::Save::WriteWorld(1)` でセーブ、`rm::Save::ReadWorld(1)` で読み込み、`rm::Save::HasWorld(1)` でそのスロットに世界があるか
- 読み込みはそのフレームの後で行います。セーブしたシーンを読み直してから、その上にセーブの状態を当てます (シーンの切り替えと同じく、スクリプトは EndPlay と BeginPlay を受けます)
- ゲームの中で消した「セーブする」の物は、読んだ後も消えたままです
- 置き場所: エディターの Play は `<プロジェクト>/Library/Saves/`、書き出したゲームは `%LOCALAPPDATA%\<exe の名前>\Saves\`

## 残らない物
- 兄弟の並びの順・物理の速さ・パーティクルや音の途中
- ゲームの中で外した部品 (読むと戻ります)
- セーブが壊れていても落ちません。読めない所は飛ばして、コンソールに出します
