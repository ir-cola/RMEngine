# Game Production

The plugin that provides the "Game" software: scenes (entities and components), Play, C++ scripts, prefabs and exporting the game.

- 3D and 2D drawing and their scene views come from the connector plugins "Game Production × 3D" and "Game Production × 2D" (under this page)
- ▶ starts Play (runs a copy of the scene). ■ stops it and returns to the scene as it was before Play
