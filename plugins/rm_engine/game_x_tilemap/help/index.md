# タイルマップ

2D のゲームの地面・壁・背景を、小さな四角い絵 (タイル) を**マス目に並べて**作ります。1 枚の画像を同じ大きさに切ったもの (タイルセット) を用意し、シーンビューで筆のように塗ります。

## 作り方

1. アセットのパネルで右クリック「作成 ▸ タイルセット」。`.rmtileset` ができます
2. 階層で右クリック「追加 ▸ 2D オブジェクト ▸ タイルマップ」。グリッドの「タイルマップ」と、その下に層の「地面」ができます
3. 「地面」を選び、インスペクターの「タイルセット」の欄に、1 で作った `.rmtileset` を入れます
4. 「**タイル**」タブ (シーンとゲームのタブの並び。無ければ「ウィンドウ」メニューから) の「タイルセット」で「絵の元を足す」を押し、タイルを並べた画像と、タイルの幅・高さ・余白・間を決めます
5. 「パレット」でタイルをクリック (ドラッグで四角に選ぶとスタンプ) し、シーンビューで塗ります

## 部品

| 部品 | すること |
|---|---|
| タイルのグリッド | マスの大きさ (既定 1 x 1 単位 = 物理の 1 m)。子の層は全部このマス目に乗ります。Transform 2D で動かす・回すと、層も一緒に |
| タイルの層 | タイルセット・並び順 (スプライトの並び順と同じ列で前後が決まる)・色。層 1 つ = エンティティ 1 つなので、階層で並べ替え・有効 / 無効・Prefab がそのまま使えます |

## シーンビューの道具

タイルの層を選ぶと、シーンビューの左上の帯に道具が出ます。

| 道具 | キー | すること |
|---|---|---|
| 筆 | B | クリック・ドラッグで塗る。Shift で消す・Alt でスポイト |
| 四角 | U | ドラッグした四角を敷き詰める。Shift で枠だけ |
| 消しゴム | | クリック・ドラッグで空にする |
| スポイト | I | マスのタイルを取る。ドラッグして四角に取るとスタンプ |
| (移動に戻る) | W / Esc | |

> 1 回のドラッグが Undo の 1 件です (Ctrl+Z)。Play 中は塗れません。

## 当たり・タグ・独自データ

「タイル」タブの「タイルセット」▸「タイル」で、絵の上に当たりの形を塗ります (形の帯: 選ぶ・なし・全部・上・下・左・右・斜め 4 つ・描く)。「選ぶ」でタイルを選ぶと、名前・当たり・タグ・独自データの欄が出ます。独自データの欄 (名前と種類) は「独自データの欄」で足します。

プラグイン「物理」があると、層の「当たりを作る」がオンの層は物理で当たります (つながった当たりは大きな箱にまとめます)。シーンビューの「形: 選択 / 全部」で当たりの線が見えます。

## 保存と書き出し

塗ったマスはシーンのファイルの中に、32 x 32 マスの区画ごとの文字 (同じタイルの続きを「値*数」と書く) で入ります。描いていない区画はファイルに出ません。書き出したゲームにはタイルセットとその画像も入ります。
