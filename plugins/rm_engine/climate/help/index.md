# 気候

同じシーンの中に、寒い所・暑い所・湿った所・乾いた所を作るプラグインです。2D と 3D のどちらのゲームでも使えます。決めた気温と湿り気は、スクリプトで場所ごとに読めます (寒さで体力が減る・吐く息が白い、など)。

> 天候のプラグインと一緒に使うと、つなぎ「天候 × 気候」が自動で入り、寒い所では雪、暖かい所では雨が降ります (天候 → 天候 × 気候 のページ)。

## シーンの設定「気候」

階層の一番上の行 (シーン) を選ぶと、インスペクターに出ます。**気候エリアの外**の気候です。

| 値 | すること |
|---|---|
| 気温 (℃) | エリアの外の気温。既定 15 |
| 湿り気 (%) | エリアの外の湿り気。0 からから 〜 50 ふつう 〜 100 じめじめ |
| 高さで冷える (℃ / 100 m) | 3D だけ。高い所ほど気温が下がる (0.6 が本物の空気くらい)。山の上だけ寒くなる |
| 基準の高さ (m) | 3D だけ。この高さで上の気温になる |

## 気候エリア

エンティティに部品「**気候エリア**」(3D) か「**気候エリア 2D**」を足します (部品を足す → 気候)。エンティティの Transform の場所・向き・大きさに付いていきます。

| 値 | すること |
|---|---|
| 形 | 3D: 箱 / 円柱 (縦が高さ)。2D: 長方形 / 円 |
| 大きさ / 広さ | 形の大きさ。Transform の大きさを掛けます |
| 境目の幅 | 縁からこの幅だけ内側へ、外の気候から**少しずつ**このエリアの気候に変わります。0 にすると縁で切り替わります |
| 気温を変える・気温 | 切ると、気温はそのまま (湿り気だけ変えるエリアにできます) |
| 湿り気を変える・湿り気 | 切ると、湿り気はそのまま |
| 優先度 | エリアが重なったとき、大きいほうを上に重ねます。寒い地方 (優先度 0) の中に、もっと寒い山頂 (優先度 1) を置けます。同じなら階層の下のほうが上 |

- 切ってある (自分か親が) エリアは効きません
- 3D のエリアは 3D の場所、2D のエリアは 2D の場所にだけ効きます
- シーンビューの「形」のスイッチ (選択 / 全部) で、エリアの**縁** (濃い線) と、**境目の内側の縁** (薄い線) が出ます。薄い線の内側は、エリアの気候そのものです

## スクリプト

```
#include "RMClimate.h"

float t = rm::Climate::TemperatureAt(rm::Transform3D(self).WorldPosition());  // 自分のいる所の気温 (℃)
float h = rm::Climate::HumidityAt2D({x, y});            // 2D の場所の湿り気 (%)
rm::Climate::SetTemperature(-10.0f);                     // エリアの外の気温を変える (すぐに)
```

読めるもの: `TemperatureAt` / `HumidityAt` (3D)・`TemperatureAt2D` / `HumidityAt2D` (2D)・`Temperature()` / `Humidity()` / `Lapse()` (シーンの設定)。変えるもの: `SetTemperature` / `SetHumidity` / `SetLapse`。
