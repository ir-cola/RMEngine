# 気候

同じシーンの中に、寒い所・暑い所・湿った所・乾いた所を作るプラグインです。2D と 3D のどちらのゲームでも使えます。決めた気温と湿り気は、スクリプトで場所ごとに読めます (寒さで体力が減る・吐く息が白い、など)。

> 天候のプラグインと一緒に使うと、つなぎ「天候 × 気候」が自動で入り、寒い所では雪、暖かい所では雨が降ります (天候 → 天候 × 気候 のページ)。

## シーンの設定「気候」

階層の一番上の行 (シーン) を選ぶと、インスペクターに出ます。**気候エリアの外**の気候です。

| 値 | すること |
|---|---|
| 気温 (℃) | エリアの外の気温。既定 15 |
| 湿り気 (%) | エリアの外の湿り気。0 からから 〜 50 ふつう 〜 100 じめじめ |
| 高さで冷える (℃ / 100 m) | 3D だけ。高い所ほど気温が下がる (0.6 が本物の空気くらい)。山の上だけ寒くなる |
| 基準の高さ (m) | 3D だけ。この高さで上の気温になる |

## 気候エリア

エンティティに部品「**気候エリア**」(3D) か「**気候エリア 2D**」を足します (部品を足す → 気候)。エンティティの Transform の場所・向き・大きさに付いていきます。

| 値 | すること |
|---|---|
| 形 | 3D: 箱 / 円柱 (縦が高さ)。2D: 長方形 / 円 |
| 大きさ / 広さ | 形の大きさ。Transform の大きさを掛けます |
| 境目の幅 | 縁からこの幅だけ内側へ、外の気候から**少しずつ**このエリアの気候に変わります。0 にすると縁で切り替わります |
| 気温を変える・気温 | 切ると、気温はそのまま (湿り気だけ変えるエリアにできます) |
| 湿り気を変える・湿り気 | 切ると、湿り気はそのまま |
| 優先度 | エリアが重なったとき、大きいほうを上に重ねます。寒い地方 (優先度 0) の中に、もっと寒い山頂 (優先度 1) を置けます。同じなら階層の下のほうが上 |

- 切ってある (自分か親が) エリアは効きません
- 3D のエリアは 3D の場所、2D のエリアは 2D の場所にだけ効きます
- シーンビューの「形」のスイッチ (選択 / 全部) で、エリアの**縁** (濃い線) と、**境目の内側の縁** (薄い線) が出ます。薄い線の内側は、エリアの気候そのものです

## 気候のタブ: 地図に塗る (3D)

シーンとゲームのタブの並びにある「**気候**」タブでは、シーンを**真上から見た地図**に、**ペンで気候を塗れます**。塗った所がその気候になります (エリアを置かなくてよい)。

- 上の「**気候**」/「**天候**」で切り替えます。「全体を見る」でシーン全体が地図に入ります
- 地図: 画面の右が +X、上が +Z。**左ドラッグ**で塗る・**ホイール**で拡大縮小・**右 / 中ドラッグ**で動かす。1 回のドラッグが Ctrl+Z の 1 回分です
- 地図の左上の道具のボタン (シーンビューの左の列と同じ): 「**筆**」(丸い筆で塗る)・「**消しゴム**」(筆で塗った所を消す)・「**ペン**」(線で囲む)・「**選ぶ**」(囲んだ形を直す)。「気候」でも「天候」でも同じ道具です。右に筆の半径と、「気候」では**マスの大きさ** (1〜16 m。細かいほどきれいに塗れます。変えても塗った場所はそのまま)
- **ペン**: クリックごとに点を置き、押したままドラッグするとなぞって点を置きます。最初の点をクリック・ダブルクリック・Enter で閉じると、囲んだ中がその気候になります (Esc でやめる)。形は筆で塗った所の上に重なり、あとで描いた形が上です
- **選ぶ**: 形をクリックで選び、点をドラッグで動かす・中をドラッグで形ごと動かす・点を右クリックで消す・Delete で形を消す。選んだまま種類の一覧をクリックすると、その形の気候が変わります
- **雨は 2 通り**: **シーン全体**に降らせるときは、シーンのインスペクター (または「天候」の下の「シーン全体の天気」) の「降水量」を上げます。**一部だけ**に降らせるときは、「**天候**」の描く層「**雨雲**」で、降る量 (%) を決めて**ペンで囲む** (筆でも塗れます)。描いた所だけ、シーンの降水量が 0 でもその量が降り、空もその上だけ厚い雲になります。雨か雪かはその場所の気温で決まります
- **雨の濃さとぼかし**: 雨雲の「**雨の濃さ**」は、目安 (ぽつぽつ・小雨・雨・大雨・嵐) を押すか、数 (%) で決めます。**ペンで囲んだ雨雲**と**筆で塗った雨雲**は、真ん中がその濃さで、**縁に向かってだんだん弱く**なります (筆で線を引くと、線の真ん中が濃く両側が薄くなります)。「**ぼかし (%)**」は縁から真ん中までのうち弱くなる幅で、0 % にすると縁まで同じ濃さです (筆かペンを選んでいるときと、形を選んだときに出ます)。雨雲が重なった所・塗り重ねた所は濃いほうになります (薄くするときは消しゴム)
- 「天候」の描く層「**雲**」: 雲の量を描きます。空の雲だけで、雨は降らせません (雲を描いていない所はシーンの天気の雲のまま)
- 上の「**見る**」: 「塗り」(描いた種類・雲・雨雲の色) /「気温」/「湿り気」/「雲」/「雨」(描いた雨雲の降る量)。気温・湿り気・雲・雨は、描いた気候・形・気候エリア・境目を全部入れた**その場所の値を色の段**で見せます (右下に目盛り。気温は「基準の高さ」での値)。カーソルの所の値も出ます
- **気候の種類**: 最初は 温帯 (15 ℃・50 %)・寒冷 (-8 ℃・60 %)・砂漠 (32 ℃・10 %)・熱帯 (28 ℃・85 %)。選んで塗ります。「＋ 足す」で増やし、下の欄で名前・色・気温・湿り気を変えます。「消す」はその種類と、それで塗った所を消します。色は地図の上だけのもので、ゲームには出ません
- **地図の境目の幅**: 塗った所の縁をはさんで、この幅でなめらかに気候が変わります (既定 8 m)
- 描いていない所は全部、インスペクターのシーンの設定「気候」と「天候」のままです。描いた所はそちらが勝ちます。**気候エリアは描いた気候の上に重なります**。「高さで冷える」は描いた所にも効きます (山の上だけ雪)
- 気候エリア (3D) の縁も、地図に線で出ます
- 「**天候**」に切り替えると、地図に雲と雨雲を描けます。右の下の「**シーン全体の天気**」(雲・降水量・霧・雷・風・テンプレート) もここで変えられます (天候のプラグインがあるとき。インスペクターのシーンと同じもの)。雨か雪かは、その場所の気温で決まります (なので天候の「雪にする」は、気候があるときは出ません)
- 地図は今は 3D のシーンだけです。2D のシーンは「気候エリア 2D」を使います

## スクリプト

```
#include "RMClimate.h"

float t = rm::Climate::TemperatureAt(rm::Transform3D(self).WorldPosition());  // 自分のいる所の気温 (℃)
float h = rm::Climate::HumidityAt2D({x, y});            // 2D の場所の湿り気 (%)
rm::Climate::SetTemperature(-10.0f);                     // エリアの外の気温を変える (すぐに)
```

読めるもの: `TemperatureAt` / `HumidityAt` (3D)・`TemperatureAt2D` / `HumidityAt2D` (2D)・`Temperature()` / `Humidity()` / `Lapse()` (シーンの設定)。変えるもの: `SetTemperature` / `SetHumidity` / `SetLapse`。
