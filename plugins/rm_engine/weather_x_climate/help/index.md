# 天候 × 気候

「天候」と「気候」の両方が入っていると自動で入る、つなぎのプラグインです。**場所の気温で、雨か雪かが決まります**。

- 気温 **+2 ℃ 以上**は雨、**-1 ℃ 以下**は雪。その間は雨粒と雪が混ざって降ります (みぞれ)
- **湿り気**で降る量が変わります。50 % でそのまま、0 % では降らず (砂漠)、100 % では 1.5 倍
- 雨粒と雪の 1 粒ずつが、自分のいる場所で決めます。だから気候エリアの境目では、目の前で少しずつ雨が雪に変わります
- 霧の色・濡れ・積雪 (Play の間) は、**カメラのいる所**の降り方で決まり、境目を越えても 2 秒ほどかけて変わります
- 天候の「**雪にする**」は使いません (場所の気温で決まるため)。空の荒れ具合 (雲・降水量・風・雷) は、今までどおり天候で決めます

> 濡れと積もった雪は、まだシーン全体で 1 つです (カメラが雪の所にいる間はどこにでも積もります)。場所ごとに分けるのは、この次に作ります。

## 試し方

1. 3D のシーンで、天候の降水量を 60 ほどにする (シーン全体の気温は 15 ℃: 雨)
2. 空のエンティティに「気候エリア」を足す: 箱・大きさ 40・境目の幅 10・気温 -5 ℃
3. 形のスイッチを「全部」にして枠を見ながら、カメラをエリアへ近づける → 薄い線を越えるあたりから雪が混ざり、真ん中では雪だけになる
