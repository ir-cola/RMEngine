# マテリアル

3D の物の**見た目** (色・絵・金属・ラフネス・でこぼこ・発光・透明) を 1 つのファイル (`.rmmat`) にしたものです。同じマテリアルをいくつもの物に使え、ファイルを変えると使っている物が全部変わります。

## 作る
アセットのパネルで右クリック →「作成」→「マテリアル」。何も選んでいなければ `Assets/Materials` に、フォルダを選んでいればその中に「新しいマテリアル.rmmat」ができ、すぐ名前を打てます。

## 編集する
アセットのパネルでマテリアルを選ぶと、インスペクターに欄が出ます。変えるとすぐシーンビューに出て、Ctrl+Z で戻せます (ファイルには編集が終わったときに書きます)。

| 欄 | すること |
|---|---|
| 色 | 表面の色。選んだ色のとおりに見えます。色の絵があれば絵に掛けます |
| 色の絵 | 表面に貼る画像。アセットのパネルからドラッグするか、クリックして選びます |
| 金属 / ラフネス | 0〜1。金属は周りを映し、ラフネスが小さいほどつるつる |
| 金属・ラフネスの絵 | 青が金属、緑がラフネス (glTF と同じ) |
| 法線の絵 / 法線の強さ | 細かいでこぼこ (ノーマルマップ。緑が上) |
| 発光の色 / 強さ / 絵 | 自分で光る色。強さを 1 より大きくするとより明るく |
| 透明の扱い | 不透明 / 切り抜き (しきい値より薄い所は穴) / 半透明 (透ける) |
| 絵の繰り返し / ずらし | 絵を並べる数とずらす量。10 x 10 の平面に 10, 10 で 1 m に 1 枚 |

## 物に付ける
物の「メッシュ (3D モデル)」の部品の「**マテリアル**」の欄に、アセットのパネルからドラッグします (＋ で欄を増やし、クリックして選ぶこともできます)。

- 形 (箱・球・円柱・カプセル・平面) は **1 つ目**の欄で塗ります。欄が無いとこれまでの灰色です
- モデルは **i 番目**の欄がモデルの i 番目の材質の代わりです。空の欄はモデルのままです。材質の無いモデル (OBJ だけなど) も 1 つ目の欄で塗れます

> 書き出したゲームには、使っているマテリアルとその絵が入ります (絵はモデルの絵と同じく GPU の形に焼きます)。
