# シーンビュー (3D)

3D のシーンを見て、物を選んで動かすパネルです。座標は **Y が上の左手系** (右・上・奥が +) です。

## カメラを動かす
| 操作 | すること |
|---|---|
| 右ドラッグ | 見回す。押している間 W A S D で前 / 左 / 後ろ / 右、Space か E で上、Ctrl か Q で下。Shift で速く |
| 中ドラッグ | 平行移動 |
| ホイール | 近づく / 離れる |
| Alt + 左ドラッグ | 選んだ物のまわりを回る |
| F | 選んだ物へ寄る |

## 道具 (左の縦の列)
| ボタン | キー | すること |
|---|---|---|
| グリッド配置 | | 押すとオン / オフ。オンの間はギズモがいつもグリッドの幅で動く (Ctrl でなめらか)。右クリックで幅 (移動・回転・大きさ) を決める |
| 選択 | Q | ギズモを出さず、クリックで選ぶだけ |
| 移動 | W | 矢印をドラッグして動かす |
| 回転 | E | 輪をドラッグして回す。球の中をドラッグすると自由に回す |
| 拡縮 | R | 箱をドラッグして大きさを変える |

## そのほか
- クリック: 選ぶ。Ctrl を押しながら: 足す / 外す
- X: ローカル / ワールド、Z: それぞれ / 中心
- グリッド配置がオフのとき、Ctrl を押しながらギズモをドラッグするとグリッドの幅で動く
- ドラッグ中に Esc: やめて元の場所に戻す

> Transform の付いたエンティティが、ここに印で出ます。メッシュ (3D モデル) の部品を付けると、その形やモデルで描きます。
