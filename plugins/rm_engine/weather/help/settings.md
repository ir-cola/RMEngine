# 天候の設定

| 値 | すること |
|---|---|
| テンプレート | 快晴・雨・大雪・吹雪 などを選ぶと、雲・降水量・雪・霧・雷・風の強さがすぐその値になる (積もる高さと風の向きは変わらない) |
| 雲の量 | 0〜100。空の雲と、暗さ |
| 降水量 | 0〜100 (小数第 1 位まで)。雨なら、ぽつぽつ → 小雨 → 雨 → どしゃぶり → 嵐 と粒も変わる |
| 雪にする | チェックすると、雨がだんだん小雨になってから雪に変わる (外すと逆) |
| 積もる高さ (cm) | 雪がここまで積もる ([雪と積もり](snow)) |
| 霧の量 | 0〜100。色は晴れ・雨・雪で自動に変わる。強い雨や雪でも見えにくくなる |
| 雷 | 光る |
| 風の向き・強さ | 雨と雪が流れる向き。斜めに降ると、屋根の下の端にも入り込む |

> 雨と雪が当たるのは**コライダーのある物**です (つなぎのプラグイン「天候 × 物理」)。
