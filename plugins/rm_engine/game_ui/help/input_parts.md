# 入力の部品

ゲームの画面で文字を打ったり、値を選んだりする部品です: **入力欄**・**スライダー**・**トグル**・**スクロール**。

## 作る
キャンバスを選んで右クリック →「追加」→「UI」→「入力欄」「スライダー」「トグル」「スクロール」。

入力欄・スライダー・トグルは、同じエンティティの「ボタン (UI)」で選ばれます (乗った・押した見た目、キーとパッドでの選択、移る先、音、押せる)。部品だけを足すときはボタンも足してください。

## 入力欄
| 操作 | すること |
|---|---|
| 押す / 選んで決定 | 打ち始める (カーソルが点滅) |
| 日本語入力 | 変換中の文字は欄の中に下線つき、候補は欄の下 |
| ← → Home End | カーソルを動かす (Shift で選ぶ・Ctrl で単語) |
| Ctrl+A / C / X / V | 全部選ぶ / コピー / 切り取り / 貼り付け |
| Enter | 決める (スクリプトに「UISubmitted」) |
| Esc・パッドの B | 打ち始める前の文字に戻す |
| ほかの所を押す | 打つのをやめる |

文字の大きさ・色・フォント・揃えは、同じエンティティの「文字 (UI)」で決めます。打っている間は、矢印や Enter でボタンが選ばれたり押されたりしません。

- **入力できる文字**: 整数・数 (小数も)・英字と数字 (全角の英数字は半角になります)
- **最大の文字数**: 見える 1 文字を 1 と数えます
- **パスワード**: ● で隠し、コピーもできません
- 1 行だけです (改行は空白になります)

## スライダー
つまみや溝を押す・ドラッグで値が変わります。選んでいるときは ← → (縦のスライダーは ↑ ↓) で動き、ほかの向きはほかのボタンへ移ります。「値の刻み」が 1 なら整数だけ。

## トグル
押すたびにオンとオフが入れ替わります。形は「チェックの箱」か「スイッチ」。「グループ」に同じ名前を入れたトグルは、同じウィンドウで 1 つだけオンになります (ラジオボタン)。

## スクロール
子の物を枠で切り取り、ホイール・中身の空いた所のドラッグ・スクロールバーで動かします。中のボタンをキーやパッドで選ぶと、見えるまで動きます。中に背の高い「中身」を置き、その中に並べると作りやすいです。UI ビューでは、枠の外の物も薄く出ます。

## スクリプト
値が変わると、そのエンティティのスクリプトの OnEvent に「UIChanged」、入力欄の Enter で「UISubmitted」が届きます。値を読む・入れる関数は `RMUI.h` のコメントを見てください。
