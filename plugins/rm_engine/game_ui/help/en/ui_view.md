# UI view

The panel where you lay out the game's screen UI (canvases, buttons, text, images, bars).

## Getting started
Right-click the Hierarchy → Add → UI → Canvas. Then create Button, Text and so on under it.

## Controls
| Input | What it does |
|---|---|
| Click | Select (Shift / Ctrl to add) |
| Drag from an empty spot | Box select |
| Drag | Move (release with Ctrl held: make it a child of that thing) |
| Double-click | Type text |
| Squares | Resize |
| Top circle | Rotate |
| Inner ring | Move the pivot |
| Alt | No snapping |
| Wheel | Zoom |
| Right drag | Pan the view |
| Drop an image asset | Place an image |
| Path points (green) | Drag to move (Shift for the pivot when they overlap) |
