# UI ビュー

ゲームの画面の UI (キャンバス・ボタン・文字・画像・バー) を置くパネルです。

## 作り始める
階層を右クリック →「追加」→「UI」→「キャンバス」。その下に「ボタン」「文字」などを作ります。

## 操作
| 操作 | すること |
|---|---|
| クリック | 選ぶ (Shift・Ctrl で足す) |
| 空いた所からドラッグ | 囲んで選ぶ |
| ドラッグ | 動かす (Ctrl を押して離す: その物の子に) |
| ダブルクリック | 文字を打つ |
| 四角 | 大きさを変える |
| 上の丸 | 回す |
| 中の輪 | 回す中心を動かす |
| Alt | 吸い付かない |
| ホイール | 拡大 |
| 右ドラッグ | 画面を動かす |
| アセットの画像をドロップ | 画像を置く |
| 道の点 (緑) | ドラッグで動かす (回す中心と重なったら Shift で中心) |
