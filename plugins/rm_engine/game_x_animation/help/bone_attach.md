# 骨に付ける

エンティティを、親 (かその上) のアニメーターが動かすモデルの**骨**に、毎フレーム合わせる部品です。剣を手に、帽子を頭に、エフェクトやカメラを骨に付けられます。付けた物も普通のエンティティです (階層に出ます)。

## 付ける
1. アニメーターの付いたエンティティ (骨のあるモデル) の**子**にエンティティを作ります (階層でドラッグ)
2. インスペクターの「＋ 部品を足す」→「3D」→「骨に付ける」
3. 「骨」の欄をクリックし、モデルの骨の一覧から選びます

## 欄
| 欄 | すること |
|---|---|
| 骨 | 付ける骨。親 (かその上) のアニメーターのモデルの骨から選びます |
| 位置のずれ | 骨から見た位置 (骨の向きで) |
| 回転のずれ (度) | 骨から見た回転 |
| 回転も合わせる | 外すと、位置だけが骨について行きます (向きはそのまま) |

- 大きさは変えません (骨の大きさは移りません)
- Play と書き出したゲームの間だけ動きます。止まっているエディターでは置いた所のまま、■ で戻ります
- 親にアニメーターが無い・その骨が無いと、コンソールに 1 度だけ知らせます
- スクリプトから骨の場所だけを知りたいときは `rm::Animator(self).BonePosition("骨の名前")` ([アニメーター](animator.md))
