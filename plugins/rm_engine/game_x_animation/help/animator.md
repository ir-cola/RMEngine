# アニメーター

骨のある 3D モデル (glTF / FBX の骨・スキン・アニメーション) を、そのモデルの**クリップ**で動かす部品です。同じエンティティの「メッシュ (3D モデル)」のモデルを動かします。

## 付ける
1. 骨とアニメーションのあるモデル (`.gltf` / `.glb` / `.fbx`) をアセットのパネルに入れます
2. エンティティの「メッシュ (3D モデル)」の「モデル」にそのモデルを入れます
3. インスペクターの「＋ 部品を足す」→「3D」→「アニメーター」

## 欄
| 欄 | すること |
|---|---|
| 状態とルール | 状態とルールのファイル (.rmanim)。入れると、ゲームの間はルールが状態を決め、その状態のクリップ・ループ・速さで流します (下の 3 つの欄も、そのとき今の状態のものになります)。「アニメーション」タブで作ります |
| クリップ | 流すクリップ。クリックすると、モデルが持つクリップ (名前と長さ) から選べます。「(最初のクリップ)」はモデルの最初のもの。モデルに無い名前は「(見つかりません)」と出て、バインドの形 (骨で動かす前の形) で描きます |
| ループ | 外すと、最後まで流して止まります |
| 速さ | 再生の速さの倍率。2 で倍、負の数で逆に流れます |
| 始めから流す | 外すと、ゲームでは最初のコマで止まったままです |

## シーンビューで見る (Play しなくてよい)
アニメーターの付いたエンティティを選ぶと、シーンビューでクリップが流れ、絵の左下に操作が出ます。

- ▶ / ‖ で再生と一時停止。ループでないクリップは終わりで止まり、▶ でまた始めから
- 時間のつまみをドラッグすると、その時刻の姿勢で止まります
- 選んでいないものは、クリップの最初のコマで止まって見えます

## Play と書き出したゲーム
「始めから流す」が付いたアニメーターは、すべて流れます。書き出したゲームには、骨とクリップがモデルと一緒に入ります。

Play 中にインスペクターで「クリップ」を変えると、そのクリップが始めから流れます。

## スクリプトから動かす
```cpp
#include "RMAnim.h"
rm::Animator anim(self);
anim.PlayClip("Run", 0.2f);   // Run を始めから。0.2 秒かけて今の姿勢から移る (クロスフェード)
anim.Pause();  anim.Resume();  anim.SetSpeed(1.5f);
if (anim.Ended()) anim.PlayClip("Idle", 0.3f);   // ループでないクリップが終わった
rm::Vec3 hand = anim.BonePosition("RightHand");    // 骨のワールドの位置 (BoneRotation で回転)
```
`PlayClip` と `SetSpeed` は部品の欄を書き換えます (Play 中のインスペクターにも出ます)。

## クリップのイベント
アセットのパネルでモデルを選び、インスペクターの「クリップとイベント」でクリップの帯にイベント (時刻・名前・数値・文字) を置きます。再生がその時刻を通ると、そのエンティティのスクリプトの `OnEvent` に届きます (送り手はエンジン)。
```cpp
void OnEvent(rm::Entity self, const rm::Event& e) { if (e.Is("Footstep")) { /* e.number・e.text */ } }
```
ループの継ぎ目をまたいでも、逆に流しても数えます。書き出したゲームにも入ります。

## 骨に付ける
剣や帽子を骨について行かせるには、子のエンティティに部品「骨に付ける」を足します ([骨に付ける](bone_attach.md))。

## 状態とルール (アニメーション タブ)
アニメーターを選んで「アニメーション」タブを開き、「状態とルールを作る」。

- **パラメーター**: スクリプトが入れる値 (数・整数・真偽・トリガー)
- **状態**: 名前・流すクリップ・ループ・速さ・出口 (自由 / 自分だけ: 元がこの状態の行と ⚡ の行だけ / 終わるまで: クリップが終わるまでは自分だけ)
- **ルール**: 毎フレーム**上から**調べ、元 (空: どこでも) が合って条件が真の**最初の 1 行**で、先の状態へフェードで移ります。一番下に「(いつも) → Idle」を置くと、どれでもないときは待機
- 条件は C++ と同じ書き方: `speed > 0.1`・`jump`・`grounded && !attack`・`t > 0.5` (今の状態の中の割合)・`ended` (1 回のクリップが終わった / ループが 1 周した)・`abs` `min` `max`
- Play 中は今の状態と当たった行が光り、「今」の欄でパラメーターを変えて試せます

```cpp
rm::Animator anim(self);
anim.SetFloat("speed", 2.0f);   anim.SetBool("grounded", true);   anim.SetTrigger("jump");
std::string s = anim.State();   anim.Play("Attack", 0.1f);   // ルールを飛ばしてその状態へ
```

## 混ぜる・重ねる
- **混ぜる**: 状態の種類を [クリップ | 1D | 2D] で選びます。1D はパラメーター 1 つ (`speed` など)、2D は 2 つ (`moveX`・`moveY`)。状態の下の図に点 (クリップ) を置き、ドラッグで動かします。表でクリップ・x・y を打つこともできます。▼ / ＋ を動かすと、その値のときの重みが出ます。混ぜたクリップの足はそろいます
- **重ねる**: 「＋ レイヤー」でレイヤーのタブが増えます。レイヤーは自分の状態とルールを持ち、体の上に重なります。重み (数かパラメーター)・重ね方 (上書き / 足す)・マスク (その骨と下の骨だけ) を決めます
