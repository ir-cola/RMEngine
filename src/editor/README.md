- `app/` 実装済み: 起動・Hub ⇔ エディターの切り替え・入力 / IME / 描画の流れ (ScreenWindow)
- `hub/` 実装済み: プロジェクト一覧・新規作成・開く・プラグインの管理 (インストール / 再インストール / 削除) と開く前の確認
- `shell/` 実装済み (枠): メニュー・ソフトのタブ枠・核のパネル (階層 (木は `tree/`) / スタート / インスペクター / コンソール / アセット)・未保存確認・外へ出したパネルのウィンドウ (FloatWindow)
- `plugin/` 実装済み: プラグインの読み込み (`plugin.json` の照らし合わせ・前提の解決は純粋でテストあり) と、プラグインがソフトを足すための API (`Software.h`)

- `inspector/` 実装済み: リフレクションの表から欄を作るインスペクター (変更は `SetFieldCommand` で Undo に積む)
- `dock/` 実装済み: パネルのドッキング。`DockLayout` = 配置の木 (純粋・テストあり) / `DockSpace` = タブ・仕切り・ドロップの目印・ウィンドウをまたぐドラッグ
- `project/` 実装済み: `.rmpf` の読み書き・`hub.json`
- `widgets/` 実装済み: テーマ・ボタン・入力欄・パネル・スクロール・メニュー・ダイアログ
